# 把想法变成可以预览的文件

在 ChatGPT 旁边编辑项目，**文件仍由你掌控**。

## 这个 Demo 可以做什么

- 阅读和编辑 Markdown、HTML 与代码文件
- 保存前检查文件版本，保留未保存的草稿
- 在侧边栏查看预览，或将静态预览放到目标网页

## 一次完整的修改

1. 打开左侧文件
2. 在源码区修改一行内容
3. 点击保存，再查看渲染结果

> 当前独立演示使用内存文件。扩展中的同一界面通过 OpenDesk Native Host 读写已授权目录。

| 文件类型 | 如何预览 |
| --- | --- |
| Markdown | 基础 Markdown 渲染 |
| HTML | 隔离的静态页面 |
| Next.js | 连接本机开发服务 |
