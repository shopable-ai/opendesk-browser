# Prompt Shortcuts R2.15 · 左侧正式迁移验收记录

时间：2026-10-20。范围仅限正式 Prompt Shortcuts、R2.14 B 视觉、现有 Service Worker 侧栏入口及针对性测试。以最新 `main` 实际源码为准。

## 产品状态及证据级别

- `trusted/page.js` 已迁入浅色圆角 B 方案：蓝色 OD、独立 38×38px 提示词按钮、5px 间距、6px 内边距、17px 圆角、轻边框/阴影与深色变量；沿用 **唯一** closed Shadow DOM/controller，未引入第二套 SDK/Host。
- 锚定使用真实 `mainRegion()` + 编辑器 DOM 矩形，不照搬原型坐标。桌面优先停靠编辑器 **左侧**；左侧净空不足时输入框上方靠左的横向布局；若该区域也不足则安全隐藏，**不会改停靠右侧**。
- 已处理小窗横排转回桌面竖排时缓存横排宽度的问题。React/SPA、导航、ResizeObserver、MutationObserver、权限和撤权监听均仍沿用现有逻辑。
- ChatGPT 开启 `webButtons` 且库为空时保留蓝色 OD 入口，最多显示四个已启用提示词；站点规则关闭、整体停用或卸载会移除注入。对其他获准自定义站点不显示 ChatGPT 专属 OD 按钮。
- OD 调用已存在的 `chrome.sidePanel.open({windowId})`，通过固定源码 `rail-open.js` 与既有 `src/sw.js` 监听，要求真实顶层 ChatGPT 扩展发送者并在消息处理时同步调用 Chrome API；拒绝来源异常和非真实点击，打开失败提示使用扩展工具栏按钮。不引入独立宿主。
- R2.14 `brand-ad-lab-r214.html` **仍是离线模拟页面**；其 B 模式视觉标尺被用于正式 CSS，不能取代安装后 ChatGPT 的实测证据。

## 验收证据与禁止误报

- 已核实 GitHub `main` 源文件写入及相关 JS 的语法解析（不等于完整 Node 构建）。
- 已使用源码隔离调用演练 OD 桥接的同步调用/拒绝非顶层发送者（不等于原生 Chrome 通过）。

- Node 全测试、正式扩展安装、网站四对话类型、真实草稿/输入法、实际 1280/1024/390px 截图与 Mac Chrome：没有本机执行证据时一律 **NOT_TESTED**。
- 有源码变更不等于已发布候选安装包。CI 必须先测试并核对候选，才可按现有流水线发布正式包；不得绕开既有产品发布验证。
- R2.14 离线预览保留不变，没有伪造原生页面截图。

## 最短收尾顺序

1. 在 main 的真实 Mac/CI checkout 跑 Prompt Shortcuts 范围测试；失败直接修复，不得只调整测试。
2. 确认正式扩展构建、站点权限、浏览器加载、ChatGPT 登录可用后，才做一次最短用户路径：安装→左侧 OD/提示词出现→点击提示词→草稿准确插入→不发送。
3. 仅在 Smoke 通过后测试四种对话状态、暗色、0–4 个、缩放与键盘/输入法/授权撤销，保留实际截图及 run URL。
4. 前置环境不满足则标 `BLOCKED`，不进入长时间自动重试。独立 95+ 维度不能以源码解析替代实测。
