# OpenDesk Prompt Shortcuts R2.14 · 快捷栏设计与交互评审

范围：`examples/sidebar-tools/prompt-shortcuts/preview/`；仅离线原型。日期：2026-10-19。

## R2.14 左侧定位纠正（2026-10-19 用户反馈）

**已修正预览按钮栏在右侧的问题，桌面默认固定为「相对于 ChatGPT 输入内容列的左侧」；不是浏览器视口右侧，也不是覆盖输入框。**

- 根因：R2.14 预览 `positionRail()` 先尝试 `cr.right+12`，只有右边放不下才选择左边，和已存在的正式 `trusted/page.js` 左侧方向相反。
- 修复：桌面始终使用 `cr.left - railWidth - 12`；内容列保留最小左右边距以容纳左侧快捷栏；窄到无法安全容纳竖栏时切换为**输入框上方、靠左**的水平栏，绝不自动切到右边。
- 390px 移动视口继续使用位于输入框上方的左对齐水平栏，不把「移动竖栏」强行放到输入框或侧边导航上。
- `brand-ad-lab-r214.test.mjs` 增加 1440 / 1280 / 1024 × 四种对话状态 × A/B/C 三方案的明确「左侧方向和间距」几何回归断言，并验证 0/4 按钮与赞助开启时不变。
- **正式文件 `trusted/page.js` 未修改**：经源码核查，它本来就采用 `mainRegion()` 和 `rect.left+12` 锚定左侧；正式视觉目前仍是透明容器、无 OD Logo，需单独迁移。
- 提交：预览 `25fb48f909105960a24dd99303e23582fea427b6`；专项测试 `1e57445446c3626f6488cfb173e866b27518c632`。截至写入时尚未在用户本地 Mac Chrome 执行，状态 `NOT_TESTED`，不能称为正式验收通过。

## 本轮决定

- **保留** R2.13 获得认可的浅色圆角容器、蓝色 OD、独立提示词底色。不得把 OD 识别标识误判为广告。
- **选择 B 作为默认方案**：约 38px 快捷钮、6px 内边距、5px 间距、17px 容器圆角、轻边框和轻阴影。A 保留 R2.13（34px）作对照；C（34px）用于狭小空间研究，不增加新的折叠按钮。
- 0–4 个提示词；0 个时 OD 可作为入口。广告入口默认关闭，仅在实验设置中显式开启，广告信息与提示词内容隔离。
- 场景：普通新对话输入框居中；项目新对话顶部为**待实站核验假设**；两类已有对话输入框在底部。三套外观使用同一页面场景、同一输入框节点。
- 不改动 `trusted/page.js`、正式 SDK、Host、广告库存或真实 ChatGPT DOM。预览里的 OD 打开的是模拟工具侧栏，不应当被称为正式 SDK 已验证。

## 改动前后对照

| 关键点 | 现有 R2.14 检查发现 | 本轮实现 |
|---|---|---|
| 设计方向 | 已具备背景容器与蓝色 OD | 保留；未重新绘制三套品牌 |
| 场景/方案选择 | 重绘被点击的分段按钮后丢失焦点 | 重绘后主动恢复相同控件焦点 |
| 输入法 | 组合输入阶段切换场景可能打断输入 | 延后场景切换，组合输入结束后执行 |
| 赞助关闭 | 原先点击详情关闭会移除赞助按钮，焦点可能丢失 | 明确将操作标注为“关闭赞助入口”，并聚焦 OD |
| 滚动后的浮层 | 快捷栏内部滚动后浮层坐标可能陈旧 | 监听滚动，必要时重新计算浮层位置 |
| 模拟新对话 | 从已有会话点击“新对话”可能继承历史模拟消息 | 新对话导航清空该模拟会话消息，不清空输入草稿 |

## 与正式扩展的差距（只读对照）

正式 `examples/sidebar-tools/prompt-shortcuts/trusted/page.js` 当前有以下既成实现：

- 独立 Shadow DOM 注入、生命周期、站点规则、真实输入框安全插入及复制回退。必须原样保留。
- 正式 `.rail` 是透明背景，48px 宽；`.item` 38×38px，独立白色按钮。
- 正式渲染只有用户提示词按钮，尚无带蓝色背景的 OD 品牌按钮及其可靠宿主打开行为。
- 正式采用 `mainRegion()`、真实 DOM 编辑器/主区域定位、ResizeObserver/MutationObserver；**不能复制 R2.14 模拟坐标**。
- 正式多状态权限和 SPA 导航是产品实际功能，原型不覆盖、不能声称已迁移。

若后续获得视觉批准，应**另开正式迁移任务**：在既有 Shadow DOM `rail` 上叠加背景容器和 OD 品牌按钮；审查点击 Logo 的真实授权侧栏入口；保留 `mainRegion()` 与剪贴板回退；逐场景检查不可遮挡输入框。赞助仍只作为实验，不默认上线。

## 轻量 Chromium 验证协议

添加 `brand-ad-lab-r214.test.mjs`，由 Node 静态解析 + Playwright Chromium Smoke 组成。测试包含：

1. 静态脚本语法、离线、4 场景、3 方案、无远程跟踪接口。
2. 0–4 个按钮与 OD 恒在、三种变体真正切换。
3. 草稿插入不自动发送；输入法阶段延后场景切换；首条模拟发送后输入框到底部。
4. Hover/键盘 Escape、赞助独立关闭/恢复、关闭后焦点。
5. 1440/1024/390 三种页面尺寸，深色、英语、日语、快捷栏与编辑器几何重叠检查。

Mac 本地命令：

```sh
R214_REQUIRE_BROWSER=1 R214_SCREENSHOT_DIR=./r214-screenshots \
  node --test examples/sidebar-tools/prompt-shortcuts/preview/brand-ad-lab-r214.test.mjs
```

如果未安装 `playwright` 或相应 Chromium，开启 `R214_REQUIRE_BROWSER=1` 会**明确失败**，不会将 SKIP 当成通过。测试是离线单文件，不能当成真实 ChatGPT 或 Mac Chrome 正式扩展通过。

**本轮实证边界**：文件结构及 GitHub 源码已核查；GitHub 文件更新已执行；上面新增的浏览器测试脚本尚未在用户 Mac 仓库内执行，状态为 `NOT_TESTED`。当前对话展示的可操作嵌入式 HTML 与其本地 Chromium 截图是用于评审的**独立演示**，不是对 GitHub 完整 HTML 的 1:1 截图证明。真实官网项目 DOM/200% 缩放/扩展安装也均为 `NOT_TESTED`。
