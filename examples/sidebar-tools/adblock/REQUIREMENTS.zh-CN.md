## 信息架构和行为
1. 概览：产品身份（蓝盾牌/说明/设置入口，避免与公共宿主双标题）→ 全局保护独立卡（真实 DNR/授权/重启/结果）→ 当前网站独立卡（当前 Tab 域名、站点开关、未知统计保留占位）→ 固定默认规则卡 → 管理已停用的网站入口。
2. 已停用的网站：真实例外数量、独立页面、真实沙箱列表、恢复需可信宿主二次确认、空状态/错误状态、返回概览。首页不常驻例外列表。
3. 设置：默认规则说明、网站例外入口、网页异常处理、现有权限/工具管理事实；不新增订阅编辑/元素屏蔽或虚假设置。
4. 状态：读取、未授权、拒绝、重启、已停用、当前网页受限、状态未知、操作忙碌、成功、撤权、DNR 回读失败、工具卸载必须明确；不得只变颜色就称生效。
5. 响应与无障碍：320/360/400/480 px 无横向溢出，键盘焦点、二级页返回、iframe 高度，浅色/深色与省动效；布局 360px 关键偏差目标 ≤4px 或 5%，实际截图才能判定。

## 分层合同
- **可信 Side Panel 固定宿主**：全局和本站真实开关、授权/重启/校验/错误、产品页导航；只可由本仓库审计源静态编译。不得信任沙箱传入的手势。
- **沙箱独立包**：当前已停用网站列表、文字和恢复意图；不能直接读/写 chrome.*、不能管理全局/本站权限。
- **既有 Chrome Service Worker**：独有 AdBlock 规则 ID 741000–741199、动态 DNR 回读与会话围栏、Epoch/安装/停用/卸载；不得为 UI 变更引入新 API/权限。
- **公共宿主**：唯一返回工具列表按钮、工具停用/卸载管理、iframe 生命周期、官方安装链；不能为了 AdBlock 替换通用权限体系。

## 实测门槛 / 证据分级
`SOURCE_VERIFIED / NODE_PASS / BUILD_PASS / CI_PASS / PREVIEW_BROWSER_PASS / NATIVE_CHROME_PASS / PRODUCT_ACCEPTED` 独立标注。没有新候选 Chrome 正式包/真实 ID/网络事件/截图时，`NATIVE_CHROME_PASS=NOT_TESTED` 且各维评分 `NOT_SCORED`。原始 SHA、P0 安全/功能和生产 CI 均为一票否决，不能凭估计达到 95/100。
