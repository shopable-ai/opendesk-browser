设计边界
  • 新的能力是「隐藏页面元素」，不是改变 Chrome DNR 网络拦截规则。
  • 保存的是本站元素屏蔽规则；关闭全局或本站保护时，预览中的元素会重新显示。
  • 演示使用预设 DOM 标识；正式版必须生成稳定、安全、按站点隔离的选择器，验证权限并处理刷新、动态加载和撤销。
