## 用户现在能做什么

当前已打开最新同源 React 预览：首页直接编辑 UA、语言、时区、视口，选择原始/美国/德国/日本；「我的环境」管理保存的档案；「检测」提供明确标注的演示读数与独立网页入口。预览保存读回、编辑、复制、删除、草稿保护均已操作验证。

预览不能改变真实 Chrome。新版安装后的授权、直接应用、停止恢复尚未完成真实 Mac 验证，因此不能承诺新版真实网页主链已经通过。旧 Host 的美国/德国应用、完整语言数组恢复、原 Session 失效及撤权证据继续复用 [R2.5 Mac 记录](mac-lifecycle-20261030.zh-CN.md)。

## 真实问题与修复

1. `preview/react/index.html` 内嵌的是旧 UI，仍显示「环境设置 / 网页验证 / 运行记录」。重新以正式 Vite 产物生成预览并刷新当前页面，现在显示「配置 / 我的环境 / 检测」。保留 `preview/index.html` 的 R3.1 设计基准。
2. 两个窗口读取同一档案后，A 保存新时区，B 的旧草稿保存会读取最新 ETag 并覆盖 A 的修改。现以原始完整档案作为编辑基线；变化或删除返回 `E_STORAGE_CONFLICT`，不尝试写入。其他档案变更不误阻止；原 CAS 和写后独立读回保留。
3. 原 Chromium 驱动仍使用旧 Tab/选择器，无法验证新版用户操作。更新既有驱动，保留原生 Node CDP/`CHROME_BIN`，不增依赖。通过结果始终标注 `FIXTURE_ONLY`。
