## 当前增量：从空白创建单页列表（2026-11-03，1.9.1）

本轮最新用户目标是“自然语言 → 当前真实网页生成规则 → 原表单/JSON 同步 → 原保存 → 真实采集 → CSV → 关闭重开复用”。先以一个公开英文图书列表完成核心链，不扩到复杂分页、详情批量访问、登录站或电子书文件下载。下方 1.8.x 的“页面推导未实现/需用户明确选择器”仅是当时限制，不能拒绝本轮已授权的空白创建；既有配置的精确修改合同继续保留。

实际入口为「扩展 → scrapyjs 采集 → 配置库 → 新建空白配置 → AI」。创建必须来自本轮明确意图与空白规则，用户不用提供 CSS、XPath、记录边界或 JSON。发送在原 prepareAI 真实事件内预留，固定包内 Controller 只读取得当前页最多 12000 字符的结构样本，过滤表单、编辑区、脚本、事件属性等；页面内容只作不可信数据。原 controllers.start/read/stop、Authority 与安装审阅继续负责网站、安装和精确文档身份，不新增平台 RPC 或第二个采集引擎。

AI 提案仍通过原 business.config.propose/apply；单页创建检查当前目标、记录边界、字段及用户指定的 CSV 表头，拒绝翻页、详情、处理与无关字段。应用前重读原观察 clientRequestId，复核 runId/resultId/样本及 Host 对原文档的权限与身份检查；相同 URL 不能替代此复核。观察与配置版本在请求中固定，停止、代际变化、未释放/unknown 及迟到响应仍拒绝应用。不自动保存、采集或下载。

固定 Controller 的精确 origin 权限新增本轮演示站 https://books.toscrape.com；这只是安装范围，生成和采集逻辑没有该站选择器、域名分支或预置配置。旧独立 HTTP Task 的冻结包和委托 pin 不变。需要按原安装更新审阅及站点授权使新候选运行。当前源码、包和真实运行状态分别以[本轮证据](../evidence/blank-page-creation-20261103.md)为准，Node/包检查不证明真实闭环通过。1.8.20 豆瓣表头回归证据继续复用，不恢复完整验收或评分。

## 4. 必须复用的真实接线

```text
可信 ToolHost 页头：AI 开合 / 来源菜单 / AI 设置 → 原唯一 Provider 设置面板
                        │ 仅展示状态通知；不是发送授权
ScrapyJS 原 App          │
├─ od-conversation-business：规则 / JSON / 配置库 / 结果（保持挂载）
└─ SharedConversationDock → SharedConversationFrame + 每实例 session
                            │ onSend / onStop
                            └─ 工具 ai-request → prepareAI 内原 ai.info / generate；原 cancel
                                  │ 数据提案
                                  └─ 工具意图与差异校验 → business.config.propose/apply
                                                             └─ 原 app-model → 表单 / JSON
```

选择**修复既有接线**：本地重画 Chat 无法保证跟随框架；复制书签业务会引入私有依赖；新建 Runtime/Chat service 超出需要。现有公开能力足以承担展示、设置入口和受控推理，没有已证实的新增 SDK 缺口。

### 设置分清两种，不让用户辨认技术层

| 设置内容 | 唯一归属 | ScrapyJS 的行为 |
| --- | --- | --- |
| AI 来源、模型、Endpoint、凭据 | 原可信 Provider 配置与唯一共享设置面板 | 页头显示框架入口；工具不读取密钥、不保存副本、不自造模型名称 |
| 字段、选择器、分页、CSV 表头和顺序 | 原 `app-model` 配置与业务界面 | AI 只通过原业务 API 改草稿；保存仍由原按钮完成 |

开合依旧通过 `setConversationState({visible,open})` 和 `opendesk:conversation-action`。正常状态的消息、输入、发送/停止、分隔条、收起由公共组件生成。仅使用现有 props 与 `feedback` 等必要插槽；不添加业务标题、设置表单或覆盖公共布局的 CSS。异常恢复控件可保留在反馈槽。

旧目标 Browser 缺少公共导出或 Host 设置入口时，保留草稿，明确提示实际缺失版本/能力；记录待更新的框架入口，不克隆设置页、不杜撰 `OpenDeskTool.openAISettings()`。只读调试拒绝真实 AI 是既有边界，不能绕过。
