本机 Agent 接入

默认关闭。只有开发者主动安装 Native Host 并授权后，外部 CLI / Codex 才能向已经打开的工作台提交脚本保存或执行请求。

外部请求仍需网站授权，并且使用同一个 RunHost、Worker、任务槽及持久结果。此设置不会自动批准任何网站，也不安装本机程序。

推荐先安装 OpenDesk 原生程序。当前开发版在正式可信 Extension ID 尚未预置前，仍需一次 opendesk browser setup --extension-id <扩展ID>；这是开发/过渡流程，不是正式产品目标。之后点击「授权并连接 OpenDesk」，无须另启 Node 或手动反复 setup。检测连接会重新尝试已授权 Native Host，不触发脚本执行；未连接不代表一定没有安装。已有 Node Host 不会被静默替换。参见仓库 docs/architecture/browser-framework/native-host-go-provider-r1.zh-CN.md。
