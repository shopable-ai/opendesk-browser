本机 Agent 接入

将本机 OpenDesk 与浏览器扩展连接。首次连接由你在浏览器中明确授权，默认保持关闭；普通脚本无需本机程序也可运行。

外部请求仍需网站授权，并且使用同一个 RunHost、Worker、任务槽及持久结果。此设置不会自动批准任何网站，也不安装本机程序。

正在读取…

先安装 OpenDesk 原生程序，再点击「授权并连接 OpenDesk」。本机连接不会自动运行脚本、访问项目文件或批准网站权限；已连接不等于本地项目 Provider 已就绪。
开发版 / 尚未连接时的说明

当前尚未配置经过核验的官方发行扩展 ID。未配对的开发版暂不能免配置连接；第一次开发安装仍可能需管理员或 AI 显式登记当前扩展 ID。已有合法 Go Native Host 的重复安装可无参数复用原绑定。原 Node Host 不会被静默替换。

高级架构与迁移指引位于仓库 docs/architecture/browser-framework/native-zero-config-pairing-r2.zh-CN.md。当前项目 ESM/npm 解析仍需独立的 Codex MCP 开发会话。
