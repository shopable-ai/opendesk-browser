查看完整数据范围与隐私说明

仅在你主动勾选后，OpenDesk 才向 Cloudflare D1 与受限的 PostHog 管理员项目发送随机安装实例标识（可跨日关联，属于假名数据）、侧边栏工具 ID 与安装启停、实际打开，以及已接入的 Prompt Shortcuts 操作类别、结果和时间。用于平台使用与可靠性分析，不发送提示词正文、聊天内容、浏览记录、网页地址、Cookie 或本机文件。另发送本机统计队列溢出、失效或过期事件的累计数量，用于标注统计覆盖缺口。新增在原有授权隔离后，按现有安装与执行记录只读统计 Page 脚本、Controller Task、Scheduler 的安装数量、逐项最新启用状态及自动执行尝试和完成、失败、未知结果。用户在工具面板真实点击运行 Task 时，也记录主动尝试（失败仍算主动使用），并从 Host 原始持久 Run/Result 核对最终执行状态。自定义脚本及任务名称仅以本机随机秘密盐转换成安装内稳定的假名代号发送，不发送原名。高频自动执行使用 UTC 日累计及单调版本。不会把脚本启动、自动调度算作主动使用；不会把执行完成直接当作已验证业务效果。新增对侧边栏逐项启停、Scheduler Definition 当前暂停状态、App Service 父级绑定状态，以及经云端持久请求绑定的自动 Controller 执行来源分类进行统计。云端启动和调度启动单独标注来源，不上传云端请求标识、网页内容或私密任务 ID。Workflow 在用户真实点击“发送”或主动运行时记录一次主动尝试，即使后续失败也算主动活跃；其 AI 自动步骤不再次计数。Workflow 仅对已完成独立网页读回并由 Host 核对原始持久 Run/Result 的业务效果发送 B 级验证事件；同一运行只统计一次，不包含网页内容、工作流源码和原始 RunId。Reading TOC 仅对用户真正点击目录且目标章节已被独立测量为可见的导航上传一次 B 级结果（不上传网址、标题和章节内容）；其自动显示、网页滚动侦测不增加 DAU。Page 已安装脚本仅在用户真实点击手动运行时，增加一次主动尝试统计（权限或执行失败仍属于主动尝试）；原始 Page 安装与持久执行回执核实完成、失败或结果未知后，另上报结果类别，不上传原始回执 ID、代码、目标网址或网页内容。Page 自动执行单独累计，不把手动使用混入自动指标。AdBlock 的真实 DNR 网络命中仍未能在普通生产环境独立观测。本次披露扩大到 Page 手动执行，既有旧披露授权不能静默扩权。

参加统计与正常使用扩展无关；关闭后停止收集并清空本机待发送队列。已到达服务器的事件按照隐私政策保留或申请删除。
