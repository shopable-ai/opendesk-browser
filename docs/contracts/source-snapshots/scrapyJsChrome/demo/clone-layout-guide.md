# 📐 布局克隆测试工具使用指南

## 🎯 功能特点

- ✅ **单次点击模式**：点击一次后自动停止，避免重复触发
- ✅ **防止递归克隆**：预览窗口不会被重复克隆进去
- ✅ **保留实际尺寸**：保存元素的真实宽度和高度
- ✅ **可视化布局**：用虚线边框和随机背景色显示区块
- ✅ **下载完整HTML**：包含目标页面URL和克隆结果的完整HTML文件
- ✅ **布局属性保留**：flex、grid、position、margin、padding等全部保留

## 🚀 使用方法

### 1. 在控制台运行脚本

```javascript
// 方式一：直接粘贴整个 clone-layout.js 文件内容到控制台运行

// 方式二：在 DevTools Sources → Snippets 中保存并运行
```

### 2. 基本操作流程

1. **脚本运行后自动启动**
   - 移动鼠标到页面元素上（会显示蓝色高亮边框）
   
2. **点击要克隆的元素**
   - 点击后会弹出预览窗口
   - 自动停止监听（不会再响应鼠标移动和点击）
   
3. **查看克隆结果**
   - 预览窗口显示克隆的布局结构
   - 每个区块有虚线边框和随机背景色
   - 底部显示统计信息

4. **下载HTML文件**（可选）
   - 点击预览窗口的 "⬇️ 下载HTML" 按钮
   - 或在控制台运行 `cloneLayout.download()`

5. **再次使用**
   - 在控制台运行 `cloneLayout.start()`

## 📝 API 接口

### 启动克隆工具
```javascript
cloneLayout.start()
```

### 停止克隆工具
```javascript
cloneLayout.stop()
```

### 下载HTML文件
```javascript
cloneLayout.download()
```

### 清理所有内容
```javascript
cloneLayout.cleanup()  // 关闭预览窗口，清除缓存
```

### 获取最后克隆的元素
```javascript
cloneLayout.getLastCloned()  // 返回DOM元素
cloneLayout.getLastHTML()    // 返回HTML字符串
```

## 🎨 布局克隆效果

### 克隆的内容包括：

✅ **布局属性**：
- `display`（flex、grid、block等）
- `position`（relative、absolute、fixed等）
- `width`、`height`（保存实际计算值）
- `margin`、`padding`
- Flexbox 属性（flex-direction、justify-content、align-items等）
- Grid 属性（grid-template-columns、grid-gap等）
- `transform`、`z-index`

✅ **可视化样式**：
- 随机柔和背景色（HSL：饱和度30-50%，亮度85-95%）
- 2px 灰色虚线边框
- 最小尺寸保证可见（min: 20px）

❌ **不包括的内容**：
- 文本内容（用标签名替代）
- 颜色、字体样式
- 非布局相关的装饰性样式

## ⚠️ 注意事项

1. **预览窗口不会被克隆**
   - 工具会自动忽略带有 `clone-layout-ignore` 类的元素
   - 预览窗口及其子元素都不会被重复克隆

2. **点击后自动停止**
   - 每次点击元素后，工具会自动停止监听
   - 需要再次克隆时，调用 `cloneLayout.start()` 重新启动

3. **尺寸保留策略**
   - 优先使用元素的实际计算宽高
   - 保留原始的 flex、grid 等布局属性
   - 小于20px的元素设置最小尺寸保证可见

4. **文本内容处理**
   - 所有文本内容被移除
   - 空元素会显示其标签名（如 "div"、"section" 等）

## 🐛 常见问题

**Q：为什么有些元素看不见？**  
A：可能是元素太小或透明。工具会为小于20px的元素设置最小尺寸，但如果元素本身是隐藏的（display: none），则不会被克隆。

**Q：如何克隆动态生成的内容？**  
A：确保在内容完全加载后再运行工具，点击已渲染的DOM元素即可。

**Q：下载的HTML文件能直接使用吗？**  
A：下载的文件是用于查看和参考的，需要根据实际情况调整和完善。

**Q：如何关闭预览窗口？**  
A：点击窗口右上角的 "✕ 关闭" 按钮，或运行 `cloneLayout.cleanup()`。

**Q：按 ESC 键无反应？**  
A：如果已经点击过元素，工具已自动停止。ESC 键只在工具运行时有效。
