## 💡 使用方法

### 方式 1：不带 return（推荐，新特性）
```javascript
// 现在可以直接使用，自动返回结果
const data = await page.eval('selector.next()');
const title = await page.eval('document.title');
const sum = await page.eval('1 + 1');
```

### 方式 2：带 return（向后兼容）
```javascript
// 显式 return 也继续工作
const data = await page.eval('return selector.next()');
const title = await page.eval('return document.title');
```

两种方式**效果完全相同**，选择您喜欢的方式即可！

## ⚠️ 常见问题

### Q1: 执行测试后仍然返回 null？

**检查清单：**
- [ ] 是否在 `chrome://extensions/` 点击了刷新？
- [ ] 是否刷新了网页标签页？
- [ ] `page.__version` 是否显示 `3.1`？
- [ ] 是否在 Service Worker 控制台执行（不是网页控制台）？

**如果都确认了还是不行：**
```javascript
// 尝试强制重载扩展
chrome.runtime.reload();
// 然后重新测试
```

### Q2: selector.next() 返回 null（但修复已生效）？

这是**正常情况**，可能的原因：
- 页面上没有列表内容
- selector 还没初始化

**解决方法：**
```javascript
// 在网页控制台（不是 background）中执行
if (typeof selector !== 'undefined') {
  selector.detectLists();
  console.log("Lists found:", selector.lists.length);
  const result = selector.next();
  console.log("Result:", result);
}
```

### Q3: 看不到日志？

确保：
1. 在 **Service Worker** 控制台执行代码（不是网页的 DevTools）
2. Service Worker 正在运行（在 `chrome://extensions/` 查看状态）
3. 控制台没有设置过滤器
