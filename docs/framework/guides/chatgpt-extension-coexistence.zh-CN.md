## 受限并行优化目标

保留动态启动最多两个父调用的现有上限、同一扩展同一文档的顺序、手动 Run 独占和权限／未知效果保护。两个固定入口独立进入，不占这两个槽；Chrome 同一网页的 JS 仍竞争主线程。优先测导航、目录和导图的排队与 DOM 扫描开销：记录导引到达、准入、执行返回、首次挂载和首次可用；先挂载首屏可操作项，长会话扫描按批次让出主线程。核对导图双身份后再走原安装／迁移链处理，保留有效实例与授权。

| 指标 | 下一轮通过条件 |
| --- | --- |
| 刷新可用性 | 相同会话、设备、视口与缓存条件下，首个入口中位数 ≤2.0 s；五项全就绪中位数 ≤5.5 s，P95 和按采集顺序前 5 轮最慢均 ≤6.5 s；五项每轮均就绪。若站点本身变慢，另记录网页条件耗时用于诊断，不用它替代总耗时门槛。 |

## 验收目标和前置条件

在一个获授权的真实 ChatGPT 顶层对话中，关闭 OpenDesk 侧栏后进入页面，不手动逐项启动，五项功能均能完成下列操作。每项在同一文档只启动一个有效实例，重复回复出现的导图按钮按回复分别计数；初始化顺序变化、一个功能停用或启动失败，其他合格功能仍可用。打开网页、重新挂载和仅点击提示词均不得自行发送消息。

实测前记录 Chrome 版本、实际 OpenDesk 加载目录、扩展 ID、已应用构建指纹、五项安装版本与 Page revision、网页模块或固定入口状态、批准范围和 Chrome 的实际站点访问；不要用项目目录里的版本代替当前安装。使用可丢弃的测试对话 A/B，A 预备多个长回合、可生成导图的 AI 回复及多个正文标题；准备一条启用的多行提示词，阅读目录和网页快捷按钮均打开，队列从空且无未知结果开始。正例打开「允许用户脚本」并确认三个动态模块各自已注册。导图用已审阅本地包；滚动导航记录实际验的是已批准预装版还是独立审阅的候选。固定队列迁移若提示旧实例未清理，先保留草稿并按产品提示刷新后重查，避免把迁移失败记为排序问题。

| 核心操作 | 通过条件 |
| --- | --- |
| 导图 + 阅读目录 | 在指定回复点开导图，确认内容属于该回复；关闭后点击一个目录章节，滚到对应正文标题。导图浮层和扩展按钮不得进入正文目录。 |
| 滚动导航 + 阅读目录 | 使用上一问/下一问或回顶/回底，再用目录跳标题。两次定位均命中预期目标，互不抢回滚动位置，也不滚动错误的容器。 |
| 提示词快捷按钮 + 队列 | 在已有草稿上点击一条多行提示词，核对插入后的文本与换行，队列与对话都无新增消息。用明确的入队操作提交一条无敏感内容的测试消息，观察等待、满足发送条件后仅发送一次，并在当前对话确认回执；回执未知时停止并对账。另用一轮中文输入法确认选词回车不会替用户入队或发送。 |
| 五项同时展示 | 分别使用 1342 × 742、768 × 742 CSS px 视口（按网页内部尺寸记录，缩放 100%）。原生编辑器和五项入口可操作，折叠入口可从明确的展开控件找到，不被扩展浮层遮挡；Tab 焦点可见，Enter/Space 按控件语义激活，关闭浮层后焦点回到入口，原生编辑器仍可继续输入。 |
| 流式回复 | 在专用对话启动一轮明确授权的测试回复。生成期间仍可用导航、目录、编辑器和队列控制；完成后新增章节／回合在适用位置出现、受支持回复恰有一个导图按钮，已有 UI 不叠挂、不抢未授权的焦点或滚动。 |

## 生命周期和负例

1. **重复加载与文档隔离。** 用关闭侧栏的直接打开、普通刷新、同一标签页 A → B → A 三条路径实测，另在两个标签页分别打开 A/B。每轮核对五项各自的可操作状态与实例数；同文档切换可重新绑定新会话，不能叠挂实例、重复执行操作或把旧回包作用到新会话，目录、导图和队列都不误用另一个会话的数据。测试中不要求可见入口按同一顺序出现。
2. **逐个停用、恢复及故障隔离。** 每轮只停用一项，确认其当前网页入口按实际清理回执撤掉或动作被拒绝；重新进页不得再挂载。其他四项仍完成各自核心操作；恢复后在当前或新文档只出现一个有效实例。再覆盖一个动态模块缺失注册或未就绪的场景，验证其余四项无需等它成功。队列停用前确认无正在发送的项目；未知结果不自动重放。
3. **两种权限分开测。** 用专用测试 Profile 关闭 Chrome「允许用户脚本」，在新文档确认导图、滚动导航和阅读目录不执行；固定队列和提示词在其余条件满足时仍分别可入队和填草稿。另单测取消整个 OpenDesk 对 ChatGPT 的 Chrome 网站访问，确认新文档五项均不挂载；对仍然打开的旧文档，验证操作不能继续访问旧授权，清理或提示按实际回执记录。恢复权限后按原安装／权限路径核对，不自动重发。
4. **范围负例。** 在不匹配这四个 AI 工具站点规则的普通 HTTP(S) 对照页，导图、滚动导航、发送队列与快捷按钮不出现；阅读目录若命中自己的普通网页授权，则仍可用。顶层文档中可能出现的 iframe 不应获得这五项业务入口。

## 证据与判定

每轮保留环境身份、URL 路径类型、文档标识、导航方式、每项「已注册／已注入、可见、首次可操作」的状态或时间、实例计数、真实操作结果和错误码。动态模块记录可读取的注册及执行回执；两个固定入口以实际页面控件、操作结果和授权拒绝为证据，不能用动态注册列表判定其缺失。记录时间仅用于比较和定位：以目标 DOM 出现为参考，区分网页自身慢、等待调度、挂载慢；不把注入先后当成验收标准。截图和时间线避免带聊天正文、草稿、凭据或完整私人会话 URL。

性能采样在 Ego 中使用同设备、同前台标签、同已登录对话和缓存策略，串行刷新以免浏览器间资源竞争污染对照；七组各至少 20 个独立文档（五项同开、五个各自单开、注入慢项）。组间交错，组内按实际采集顺序写入，不能事后删去慢轮或未挂载轮。采样窗口统一为刷新后 15 s；目标 UI 未就绪记失败，站点本身不具备测试前提或采集器失败才可作废并单列原因和原始记录。每项用同一导航时钟记录页面依赖、业务入口首次挂载和控件首次可操作的时间；依赖后等待逐轮相减，再算中位数、最近秩 P95 和最大值。动态项同时保留该轮自动执行回执，拆出请求到达、准备、等待调度槽、获槽到派发、派发到挂载、挂载到可操作；页面依赖和后台流程可能重叠，不能把各自的耗时相加当总耗时。权限负例仅在可单独管理权限的专用 Profile 执行，记录其与性能环境的构建／安装版本对应关系；两个 Profile 共享会话证据不能代替权限回执。

慢项对照使用[导航测试包构建器](../../../scripts/build-chatgpt-coexistence-slow-candidate.mjs)，参数依次为未占用的导航 revision、冻结项目目录、原 Page 安装包。构建器先重建并逐字节比对原包执行源码，再生成保留原执行格式和网页范围的测试包和同目录 `fixture.json`，记录原包与测试包摘要。不要直接用仍在变动的工作树作为已实装版本的依据。当前已基于有真实回顶证据的导航 0.4.41/r43 生成 `artifacts/chatgpt-extension-coexistence/slow-candidate-r900000002-fD9j8g/`；该派生包尚未安装。

测试包仅在指定的专用 Ego Profile 经原安装审阅链使用。七组和专家签审都记录同一测试候选身份，所有包含导航的组使用同一包字节；普通组不启用延迟。只在慢组的指定 ChatGPT 标签上，先确认当前标签和目标对话，再用 Ego 的 `page.cdp('Page.addScriptToEvaluateOnNewDocument', { source: fixture.trigger })` 注册下一文档的标记，随后用 `page.reload()` 普通刷新。在同一个 Ego 执行轮次的 `finally` 用 `Page.removeScriptToEvaluateOnNewDocument` 按返回的 `identifier` 移除，确认清理后才采下一轮。该触发器不在当前文档执行；受管导航入口消费精确标记一次，在父调用内异步等待 2 秒，再挂载控件。标记不用于正常包或日常 Profile。

每个包含动态项的样本都保留匹配实际标签 ID、Chrome `documentId`、已安装程序 ID、revision 与哈希的 Page Authority 回执。检查器用页面 `timeOrigin` 与后台 `schedulerClockOrigin` 把时间转到同一轴。从获槽到回执完成的区间若同时重叠超过两个动态父调用，直接判失败。回执完成可能早于实际释放槽位，所以还要用调度器的定向测试验证上限、同文档顺序和手动 Run 独占。慢样本另从 `result.resultText` 读取延迟的起止点，核对它在目标调用获槽后、派发后、挂载前，且不越过调用完成时刻。另一动态模块须在这段区间内实际派发或完成，只有已显示的 UI 不算通过。只有构建或模拟测试通过时，慢项实测仍为 `NOT_TESTED`。

**独立专家放行线。** 由未参与本候选实现的评审者查看同一构建和五个已安装包的原始性能记录、UI 操作和权限回执，按下表各给 0–100 整数分，列出依据、扣分和未解决问题，并签审候选指纹。每项至少 95 分、加权总分严格 **大于 95.00**（不先四舍五入），且 P0/P1 为零。任何性能硬门槛失败、关键项未测或证据缺失，整体验收不得通过。

| 维度 | 权重 | 评审证据 |
| --- | ---: | --- |
| 性能和故障隔离 | 30% | 刷新和依赖后的延迟、单项与五项同开、慢项对照、主线程跟踪和阶段归因。 |
| 核心 UI 和可访问性 | 30% | 五项真实操作、窄宽度、键盘和焦点、中文 IME、流式输出。 |
| 权限和文档隔离 | 25% | 两类权限的拒绝与恢复，旧文档、跨会话、非目标站点和 iframe。 |
| 可靠性和可复测性 | 15% | 每文档实例数、逐项停用与恢复、发送回执和未知不重放、构建与原始证据可对应。 |

使用 [Ego 刷新探针](../../../scripts/capture-chatgpt-coexistence-refresh.mjs) 时，在已有测试 TaskSpace 的 Ego Node 脚本中按绝对路径导入 `captureRefresh(page, group)`，每次调用只做一次同路由普通刷新。探针从新文档开始每隔约 50 ms 取样，持续满 15 s，即使入口提前就绪也继续检查晚到的挂载。记录布局、命中、实例峰值、视口、前台可见性和采样开销；提示词与目录的封闭 Shadow DOM 用定向 CDP 只读检查，其就绪时间包含这段观测延迟。检查器核对五项的原始结果，拒绝单开对照的非目标入口、采样期间的重复实例和环境异常。挂载和就绪是首次观察值；队列按钮就绪仍需另测入队和发送。

探针不切换安装、权限或慢项开关，也不产生 Page Authority 回执。将原始结果与同一文档及安装身份的回执对齐后，再填证据清单；缺失、重复等产品失败要保留，环境无效轮次另记具体原因。模拟页面能验证探针，不能替代真实会话或性能跟踪。

运行 [共存验收检查器](../../../scripts/evaluate-chatgpt-extension-coexistence.mjs)：

```sh
node scripts/evaluate-chatgpt-extension-coexistence.mjs artifacts/chatgpt-extension-coexistence/evidence.json
```

检查器核算实测样本、门槛、UI 结果和签审分数；采集和专家判断仍须实际完成。退出码 `0` 表示证据通过，`1` 表示门槛或证据不完整，`2` 表示缺少／无法解析证据。清单格式：

| 字段 | 内容 |
| --- | --- |
| `schemaVersion`、`candidate` | `1`；`artifact` 指向根据实际 Ego 运行与产品安装读回保存的身份 JSON。该 JSON 和清单均含 `browserVersion`、`chromiumVersion`、`extensionId`、绝对 `loadPath`、`build`、`mode`，以及按功能 ID 列出的 `installations`（每项含字符串 `version`、`revision`、`entry`；动态项另含 `programId`、`sourceHash`、`manifestHash`；慢项目标另含 `packageSha256`）。读回记录另留实际加载路径、已应用构建／watcher 和授权的取证出处。`fingerprint` 是该 JSON 文件原始字节的 SHA-256，可用 `shasum -a 256` 计算；检查器同时核对哈希和两处身份字段。 |
| `measurement` | `artifact` 指向采集条件、原始顺序和例外记录；`viewport` 是统一的网页宽高（CSS px）。`samples` 以实采顺序每文档一条，含 `candidate`、`document`、`tabId`、`timeOrigin`、`group`（`all`、`slow` 或 `single:<功能 ID>`）、`captureArtifact`（探针返回的原始 JSON）及 `points`（按目标功能列出 `dependencyMs`、`mountMs`、`readyMs`、`usable`、`instances`）。五项 ID 为 `prompt`、`queue`、`mindmap`、`toc`、`navigation`。缺失或不可操作要保留该轮。 |
| 动态项的测量回执 | 含动态项的样本另填 `receiptArtifact`；`document` 与回执的 `documentId` 一致。回执文件是 JSON，对象 `executions` 按动态功能 ID 保存 Page Authority 原自动执行记录及其 `result.startupTimings`，至少保留 `schedulerClockOrigin`、`schedulerQueuedAtMs`、`schedulerReadyAtMs`、`schedulerLeaseAcquiredAtMs`，以及外层派发和完成时间。删去聊天内容、私人 URL 和安装令牌，不删时间、版本、哈希和用于关联的文档字段。 |
| `slowTarget`、`slowFixture` | `slowTarget` 是被延迟的动态功能；`slowFixture` 记录 `candidate`、`artifact`（构建器生成的 `fixture.json`）和 `packageArtifact`（原测试包）。慢项的回执保留 `result.resultText` 里的延迟窗口。 |
| `trace` | 跟踪结果含 `candidate`、`reviewed`、`attributedTasksAtLeast50Ms`、`artifact`。无法归因须保留未测状态。 |
| `ui` | 按下列用例 ID 记录 `candidate`、`status`、`artifact`。只有实际通过才记 `pass`；证据须含预期结果、实际动作和回执。 |
| `expert` | `candidate`、`reviewer`、`implementer`、`p0`、`p1`、`artifact`（签审记录），`scores` 含 `performance`、`ui`、`permission`、`reliability`。 |

所有 `artifact` 填相对于清单文件的非空证据文件路径。UI 用例键与取证动作一一对应：

| 用例键 | 要留证的结果 |
| --- | --- |
| `direct-and-refresh` | 关闭侧栏，直接打开会话并普通刷新。两次均有五项可操作入口，各有一个有效实例，且无自动发送。 |
| `mindmap-toc` | 从指定回复打开导图，内容对应这条回复；关闭后目录能跳到指定标题，目录不收录扩展 UI。 |
| `navigation-toc` | 先导航到指定回合，再用目录跳标题；两次定位均正确，不争抢滚动。 |
| `prompt-draft` | 在已有草稿上插入多行提示词，文本和换行正确，队列和对话均无新增消息。 |
| `queue-once` | 明确入队后观察等待和一次发送，在当前对话核对唯一回执。 |
| `queue-unknown` | 未知结果不自动重发，仍有可查看和对账的状态。 |
| `ime` | 真实中文输入法选词的回车不误触入队或发送。 |
| `wide-and-narrow` | 1342 × 742 和 768 × 742 CSS px 下入口可命中，Tab 焦点可见，按键激活和浮层关闭后的焦点归还有效。 |
| `streaming` | 流式生成期间编辑器、队列、目录和导航仍可操作；完成后新增内容可用，无重复入口。 |
| `spa-return` | 同标签 A → B → A，只更新当前会话，旧回包不串入，不重复挂载。 |
| `two-tabs` | 两个标签分别打开 A/B，目录、导图和队列数据各自对应当前会话。 |
| `disable-and-restore` | 五项逐个停用和恢复；当前入口清理或拒绝，新文档不再挂载，其余四项保持可用，恢复后仅一个有效实例。 |
| `dynamic-failure` | 一个动态模块缺失注册或未能启动，其余四项无需等它成功。 |
| `userscripts-off` | 在新文档，关闭用户脚本后只有三个动态模块停止；队列可入队，提示词可填充草稿。 |
| `site-access-revoked` | Chrome 撤销整个 OpenDesk 的 ChatGPT 访问后，新文档五项均停止，旧文档也不能继续使用旧授权。 |
| `permissions-restored` | 沿原路径恢复权限，入口重新可用，同一文档不叠挂，不重发。 |
| `offsite` | 不匹配的普通网页无四个 AI 工具入口；目录按自己的批准范围判定。 |
| `iframe` | iframe 未获得五项业务入口。 |
