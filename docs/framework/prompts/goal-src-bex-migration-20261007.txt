  远程脚本、module、字符串 onload 继续拒绝。不承诺能强行停止已派发且可能产生外部效果的 MAIN 代码。
  没有确认独立公开“写入任意 HTML”API；content() 是读 HTML，$/$$ 在 Worker 返回快照。
