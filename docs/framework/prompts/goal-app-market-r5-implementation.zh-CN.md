## 本轮必须交付

1. 同仓 `src/market-site` 独立模板、样式、搜索／少量分类、详情／固定版本／套装页面、连接客户端及帮助；build 脚本只负责构建、校验、路由、输出。构建完整且不依赖旧 dist。
2. 网站与扩展共享纯数据和 token；保留 Catalog／官方生产者，不复制扩展整页到 HTTP，不把网站依赖打入 SW，不建立第二套安装数据库、权限、RPC、注册表或执行框架。
3. 比较随包交接、准入类型远程固定版本、组合架构，选一条路线实施。默认随包官方 Sidebar 完成闭环，同时保留已有远程依赖能力并定义 Page／sandbox／Task 未来整包分发边界。
4. 单一受控来源配置：构建模式、HTTPS 正式 Origin／扩展 ID、开发 loopback／实际 ID、协议、核验获取地址。开发仅进开发包，生产拒绝开发和未授权来源；展示 metadata 不能等同安装信任。
5. Chrome 外部消息仅 PROBE 与 OPEN_INSTALL_REVIEW，严格 `opendesk.market.intent.v1`，只含请求 ID＋固定 app/version 或 collection/revision；拒绝代码、URL、运行、批准、跳转和用户数据。
6. 核对真实 sender Origin／URL／顶层 frame／tab／document／浏览器协议条件；不信任正文来源，不进通用 SDK／RPC／RunHost。
7. 扩展自己生成私有固定审阅 URL；一次集中审阅。重复同意图同内容复用，同 ID 不同内容拒绝，新请求不得替换正在审阅候选。官网离开后可信页仍可本地审阅。
8. 意图 TTL／容量、全局＋Origin 限流、跨 Worker 恢复、开页与写入之间中断核对；不宣称未实现的原子性。保护原安装事务及恢复数据，不把交接响应当安装成功。
9. 原安装器锁、baseline、规范化摘要、来源、版本、宿主兼容、必要权限在提交时重查。未知结果先恢复，不能自动重放；安装不自动运行，权限独立主动授予，正常使用复用。
10. 固定版本和套装 revision 不变；历史来自受控发布快照，缺包不替换。更新保护数据与迁移状态；代码回退不承诺数据回滚。来源、hash、签名、审核分别表达。
11. 真实本地 HTTP：保留 `npm run build:market-site` 与 `python3 -m http.server 43132 --bind 127.0.0.1 --directory dist/app-market-public`；新增一键命令必须入 package.json 且实测。先核对端口，不杀其他进程，变更端口同步配置。
12. 页面、交接、审阅、真实安装记录、实际打开使用及重启分别证明；优先可选 Markdown 首装，并在 `http://127.0.0.1:43111/demo-form.html` 单独验证网站授权和页面能力。不得伪 sender、直接写安装表、原型内存冒充真实安装。

## UI 与隐私要求

UI 与 UX 分开检查：层级、token、字号、gutter、间距、卡片、控件、图标及可访问名、窄屏／长标题／深色／125%与200%缩放／溢出／焦点；详情优先用途、截图、运行位置和主要操作。哈希、协议放技术区。

保留 Sidebar 图标入口、发现与本机搜索的既有职责、选项卡记忆和最新工具布局，不增加重复同级导航。应用 alert/confirm/prompt 不参与正常安装使用；Chrome 必要权限使用真实入口。连接超时只显示无法连接，不断言未安装；官网没有真实来源时不能伪造已安装。

网站不读取或上传完整安装清单、浏览历史、当前网页内容、笔记、Cookie、Token 或 Native 配对；第三方说明和图片安全渲染，交接页不引入多余第三方脚本。

## 必须分别保留的测试范围

首次安装／已安装／更新／固定版本缺失；无接收端／错误 ID／协议不支持／超时；非法来源／错误端口／iframe／额外字段；相同意图重发／同 ID 内容冲突／候选防替换；官网关闭后审阅；Worker 冷启动／停止／交接窗口中断；baseline／摘要／来源／容量；未知结果恢复；更新后用户数据；Chrome 正常重启；生产拒绝开发来源。

更新原先禁止 externally_connectable 的包校验及原生断言为按模式精确核对来源，保留拒绝行为。不用源码正则代替用户行为，不为新对话无关全量重测。证据绑定源码与差异、网站 build ID、扩展 packageHash、目录及应用身份、Chrome 版本、实际扩展 ID/Origin、操作／结果及 PASS/FAIL/NOT_TESTED/BLOCKED 范围。

## 独立评分与硬门槛

至少逐项报告：产品架构、网站 UI、UX、真实安装更新卸载使用、安全、隐私、固定版本套装事务、本地 HTTP、正式 HTTPS、兼容性性能维护、故障恢复与证据完整性。

每项分别给设计分、实现分、证据等级与状态、未关闭问题、文件结果和下一步。设计与实现均须 ≥95 且对应证据满足才完成该维度验收；不得平均分抵消，不继承上一轮综合 96。材料不足用待评／NOT_IMPLEMENTED／NOT_TESTED／BLOCKED；设计 95 不能替代实现。

P0 必须零。非法网页安装执行、外部入口进入通用执行、候选不一致／被替换、生产接受开发、来源摘要baseline权限可绕过、未知自动重放、数据损坏不可恢复、伪造 sender／安装或不匹配旧证据，均不准验收通过。核心恢复 P1 未关闭则不得 ≥95。

由非主要实现者分别做架构安全、UI／UX、安装恢复证据审阅。每个扣分有具体影响和整改；加分需要实际代码／有效证据，不删失败、降合同或改范围。
