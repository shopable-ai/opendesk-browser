# 扩展「关于」关键测试与专家评分

日期：2026-11-20。验收对象：[扩展「关于」产品设计](../product/extension-about.zh-CN.md)。开发检查记录见文末；正式产品验收和独立评分尚未执行。

| 编号 | 必过场景 | 通过条件 |
| --- | --- | --- |
| A01 | 从多个扩展的设置或详情直接读版本 | 分别打开沙箱应用、固定可信应用、普通网页增强和具有专属详情的网页增强。有设置入口的扩展，在原设置页底部看到默认展开的「关于此扩展」，首行直接可读「已安装版本」；无设置入口的条目从「更多 → 详情」看到同样默认展开的分区，不出现空齿轮。各入口统一使用侧栏折叠分区的标题、边框、间距和箭头。在同页收起后刷新数据或切换语言，仍保持收起；退出重开或切换到另一扩展时默认展开。详情首页和日常子页不重复展示版本卡。普通行点击仍按原主操作。 |
| A02 | 对外只显示版本号 | 用已安装 1.2.3、可用更新 1.3.0、Page 修订 r27 做样本；「关于」与常规更新摘要只显示对应版本，修订保留在技术区。没有可靠版本的旧 Page 在「关于」显示「版本未记录」，无需重装。若为组合应用，不混淆父应用、配套 Page、OpenDesk Browser 或目录版本。 |
| A03 | 配置可选字段并经历安装和升级 | Sidebar Tool 分别验证历史 v1/v2 包，以及带作者、开发者网站、支持链接的新候选；Page 验证离线包和固定 USER_SCRIPT 路径。走既有安装或更新审阅，重开详情及刷新后从真实安装记录读回。新版本删除字段后该行消失，不继承旧版本字段。未安装候选只显示自身真实资料；空作者、空网站、单字段、完整字段均不影响布局。 |
| A04 | 对照第三方、目录离线与旧包 | 用本地包与同 ID 目录条目、不同版本或不同摘要作对照；本地数据独立，不能借用目录的作者、网站或已验证标签。关闭目录连接后，旧包仍可开、查版本及使用，现有本地更新审阅和卸载不受影响。旧包规范字节、摘要及既有授权保持一致。 |
| A05 | 对外链接只做导航 | 测试有效 HTTPS，第二个字段指向同址，含凭据、控制字符、不合格协议及相对地址的文本。非法值不可点击；作者按纯文本；合法目标域名可辨、点击仅开新标签页，无 opener/referrer，未点击无请求或权限提示；点击也不安装、不执行、不授权。 |
| A06 | 窄屏、键盘、缩放与语言 | 320/360/400/440px 侧栏及 960px 独立视图，覆盖实际 200% 缩放。长版本、作者和域名可换行，页面无横向滚动，不遮主按钮。Tab 可聚焦「关于此扩展」，Enter 或空格可收起和展开，收起后不会 Tab 到隐藏链接。用 Tab/Enter/Escape 检查行级菜单、返回后的焦点、筛选和滚动恢复。核对中文简繁、英文、日文的字段名和缺值文案，无原始翻译 key 或依赖悬停才可得的信息。 |
| A07 | 回归原有设置、草稿和权限 | 至少一个有现成框架设置的代表工具从已有设置访问同一信息，返回时原实例与草稿保留。安装更新、停用恢复、权限/诊断及旧网页清理行为仍走现有流程。详情打开期间并发更新、卸载或重载，不展示混合身份的数据，不复活旧详情、重放写入或授予权限。Controller 既有详情仍显示自己的版本及作者。 |
| A08 | 设置页的间距和独立分组 | 在当前开发版的真实「扩展」列表逐项检查；从设置按钮进入，页头和扩展中心的顶部留白一致。在 320px 和一个常用侧栏宽度（如 400px）查看分组对齐，长标题与正文可换行，无水平溢出或按钮裁切。页面只有一个「关于此扩展」，与其余分组并列，无外卡或重复折叠；初次进入和返回后再进入均默认展开，直接显示本机已安装版本。检查配置、安装信息和维护入口；日常开发检查无需实际更改设置、授权或卸载。 |
| A09 | 使用说明的开合与焦点 | 有说明的扩展使用统一折叠区，第一次进设置和返回后再进均收起；鼠标点击与 Tab 后按 Enter 或空格均可开合，键盘焦点清晰可见，展开内容完整、折叠后不可误聚焦隐藏内容。无说明项不显示占位。记录实际使用鼠标和键盘的入口与宽度。 |

先在现有持续开发入口记录一条最短真实操作，再做受影响的包验证、只读投影和 React 行为测试。复用现有包检查及扩展中心、已安装 Page 行为测试；独立证据覆盖旧包字节/摘要、无授权变化及页面身份回读。定向测试证明局部合同，正式评级另需用同一冻结候选在真实 Chrome 的 Side Panel 复核。遵守已有 dist/development watcher 和专用候选/Profile 边界；普通网页模拟不能作为扩展安装或 Chrome 权限的证据。

开发阶段的设置页盘点随当前构建记录：扩展名称与安装 ID、列表过滤范围、点击路径、页面归属、已读版本、问题、覆盖宽度及截图。逐项标明通过、无设置入口、入口阻塞（注明原因）或未验证（注明未覆盖内容）；如果详情可用，单独记下详情验证。真实 Side Panel 和独立扩展标签页分开报告，标签页用相同页面和宽度测试也不算 Side Panel 通过。

| 独立评分维度 | 满分 | 证据 |
| --- | ---: | --- |
| 入口可发现性和信息层级 | 20 | A01：设置或详情中的统一分区、版本首行默认可见、无空设置入口 |
| 信息准确性，以及旧版和不同扩展类型的兼容 | 30 | A02–A04：安装读回、版本与修订分离、旧字节和同 ID 边界 |
| 可选字段和外链的可信呈现 | 20 | A03–A05：配置往返、缺失处理、身份与链接隔离 |
| 窄屏、键盘和语言 | 15 | A06：实测界面、焦点与跨语言证据 |
| 现有操作与状态保护 | 15 | A07：原流程、草稿和并发身份回归 |

**验收门槛：独立评审总分严格大于 95（整数计分至少 96/100），A01–A07 全部通过。** 由未负责实现的评审者按每维实际证据给分，逐项写明扣分和可复查依据。错误版本、冒用发布者、链接扩大权限、旧包失效、核心流程退化，均为否决项，不可由其他维度抵消。记录同一候选的源码指纹、加载包摘要、Chrome 版本、实际加载路径、样本身份和操作/读回证据。任何必过项没有证据就记为 NOT_TESTED；不填写推测分数，也不把源码或模拟通过计作正式验收。
