# UI 布局规范 R27 · Tailwind rem 基准与跨页面一致性

日期：2026-10-12；仓库 `shopable-ai/opendesk-browser`；唯一写入分支 `main`。本文件是专项工作流记录，不替代原生证据与历史工作流。

## 审计事实

- 已有 `src/ui/design-tokens.css` 定义 4/8/12/16px、圆角、34px icon 及语义色，Side Panel 的 R26 规范和测试存在；上一轮 Side Panel R21 CI、R19 静态 Chrome、侧栏工具构建成功（具体候选见 [R26 记录](sidebar-tool-spacing-r26.md)）。
- `package.json` 精确锁定 `tailwindcss` / `@tailwindcss/cli` 4.3.3；当前**实际启用 Tailwind 离线构建的是 Native Workspace**，不是 Side Panel、Settings、Marketplace 或所有第三方工具。
- `src/native-agent/workspace.tailwind.css` 原先在 `:root` 设置 `font-size:13px`，Tailwind v4 `rem` 工具间距/文本相对其计算：以默认 16px 基准 `gap-2=8px`，13px 根字号却变为 `6.5px`；`p-3` 从 `12px` 变为 `9.75px`；`text-xs` 从 `12px` 变为 `9.75px`。媒体查询内 `rem` 使用浏览器初始字号，**不能错误断言 `:root` 13px 把 `sm` 变成 520px**。
- `src/ui/design-system.css` 基础控件仍出现 9/10/11px 的零散 spacing，虽然已有公共变量；Side Panel 工具沙箱与网页注入 UI 需要严格边界，不能共享特权 CSS reset。
- 历史独立工具如知识收件箱、阅读目录及市场页面仍存在本地设计值，暗色主题、200% 缩放、触摸目标需逐个核查；本次不得宣称已经统一所有历史 CSS。
