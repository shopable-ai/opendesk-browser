1. **Local Project（P0）**：不能仅把 startLocal 原样复制到 local-project.js。必须先让原 Provider capture/resolve/assertReady/epoch 由一个项目所有者完成，将已冻结源码与 RunHost/Native page 的真实回执作为明确结果返回；Editor 只绑定 Run/Result/Stop。新方法不得改变 onClaim UI 发生时序、pending 轮询取消、install proof 与效果未知。缺 Native/Chrome 回归证据时保持 BLOCKED。
