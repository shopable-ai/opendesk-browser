# Sidebar R19 — 五页签统一间距与组件圆角

日期：2026-10-10；执行目标：OpenDesk Browser `main` 的真实 `src/ui/tool-shell.css`，不新增页面、运行时、权限或依赖。

## 已定位问题

- 「开发」视图的全局 `details`、当前网页区块、编辑器状态、多个高级区块分别拥有不同的上下 margin/padding（6、7、8、9、10、11、12px），实际会累积，导致相邻行的空白不规则。
- 「发现」搜索与导入使用普通 8px 圆角按钮，筛选项却是 18px 胶囊按钮；导航、卡片、工具小程序、工作流又采用 7/9/10/11/13px 的混合半径。
- 五个页签：我的、发现、工作流、开发、工具；完整任务目录及工具独立页复用组件，因此同时纳入角度与回归检查。

## 统一设计基准（不是所有组件同一圆角）

| 类别 | 基准 | 处理 |
| --- | --- | --- |
| 普通按钮、输入框、选择器、icon 按钮 | 8px | 使用 `--radius-control`；顶部活动页签为强调下划线保留 0px |
| 卡片、工具面板、嵌套信息表面 | 12px | 使用 `--radius-surface`；分组内列表行可保持平直，以外层圆角限定整体轮廓 |
| 提示徽章、开关拨钮 | 完整胶囊 | 语义上才使用圆形/胶囊；不再给普通筛选按钮强制 18px |
| 页面垂直节奏 | 4/8/12/16px | 开发页让容器负责 8px 主间距，子区块内边距和分隔线说明信息层级 |
| 发现筛选 | 紧凑分段控件 | 三项共用轻边框容器，内部每项 8px 圆角；当前网页/全部/停用的 `aria-pressed` 行为不变 |
| 响应式/可访问性 | 原合同保留 | 保留 300/360/420/520px、200% 缩放、键盘聚焦、无横向溢出和真实可信 Run/Stop 边界 |
