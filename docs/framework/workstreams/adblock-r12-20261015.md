## 安全边界与复查要点

沙箱 UI 不直接操作 `chrome.*`；可信 Side Panel 通过现有 Host / 真实点击向单一 SW 发送固定操作；服务再次验证安装身份、SHA-256、安装 Epoch、live sender/document 及 Chrome 权限。官方固定业务代码经 Git Blob 指纹绑定，不能由动态工具包注入。

AdBlock 自有 dynamic DNR ID `741000–741199`；基准 block 优先级 1，精确 HTTP(S) 主机例外 `allowAllRequests` 优先级 2。Stay Focus 使用 `730000–730199` 且重定向优先级 ≥20。任何清理只删除 AdBlock 自己的规则。不开主框架拦截，不采集页面内容、完整 URL、请求历史。该架构不等于 AdGuard/uBOL 全功能。
