## 独立审查修正

- 批量计划使用滚动的预期基线，本批成功项造成的容量变化不触发无意义重审；计划外并发变化才使受影响项失效。
- 意图过期只终止未批准请求；已提交操作持久恢复，不能被短期 nonce 生命周期删除。
- unlisted 退出发现但固定合法链接可安装；withdrawn 禁止新安装；revoked 走安全撤销处理，三者不混用。
- environment 采用 unknown/checking/assessed 加多项安装/使用 blockers，没有来源网页不等于受限或已支持。
- Sidebar 迁移安装本身不运行业务动作；Page 日后通过目标设备验证、授权和明确启用后仍遵守其既有匹配生命周期。
- 已发布/未列出采用正向准入；hash 正确的草稿仍不可安装。预检同时核对批内和现有本地槽位的作者归属。
- 版本审阅绑定确定发行和原安装基线，并检查数据 schema 兼容；不能将任意一次旧批准用于新目标。
- 固定版本详情、分享、公开交接、确认及套装成员链接均保留原版本。旧 revision 的名称、说明、成员和可选性使用独立快照。
- reconnect 场景复用 unknown→reconciling→同一演示事务回执；同套装或同迁移清单在途/未知时返回原操作，避免新批次覆盖。
