# R15.6 — src/runtime → src/libs 最终目录收敛

日期：2026-10-11。范围：OpenDesk Browser main；这是对 R15/R15.4/R15.5 现有库体系的目录清理，不重建库框架。

## 源码检查与变更

- 唯一正式内置库目录是 `src/libs/`。其中 `runtime-contract.js` 定义 ABI/世界/资源路径，`catalog.js` 扩展作者元数据，`loader.js` 加载并核对固定扩展包资源，`core.js` 注册 API。
- `src/libs/runtime/bootstrap.js` 是新体系的必要资源，不能因名字带有 runtime 而删除。
- 旧 `src/runtime/builtin-libraries/` 含 4 个仅用于路径兼容的转发入口和 1 个身份校验实现。已将 `identity.js` 迁至 `src/libs/identity.js`，保留 `builtinIdentity` 与 `assertBuiltinIdentity` 原行为和 `E_BUILTIN_VERSION_UNAVAILABLE` 错误码。
- Controller、Task、Page 候选验证、已安装 Page 程序等调用处统一直接导入 `src/libs/{loader,identity}.js`；删除 5 个旧源码文件，不再保留两套导入路径。
- 随迁移更新源绑定 Chrome fixture、`tests/environment` 旧导入和构建分析用例，并更新本地只读诊断输出到实际 `libs/runtime/page-core.js` / `libs/manifest.json`。
- `src/vendor` 中的旧 jQuery 副本已经由 R15.5 清理，不在本轮重复迁移，保留 `src/libs/vendor/jquery/3.7.1/` 中受 SHA/字节校验的单一源文件。
- `tests/environment/libs-layout-r156.test.mjs` 要求干净检出的仓库不再出现 `src/runtime`，禁止 src/scripts 恢复旧路径，并覆盖 ABI/SHA 版本拒绝行为。

## 风险与验收分级

这次只移动模块位置和导入，不改固定资源 ABI、SHA、公开方法、Worker/Page 世界、授权/CSP、`libs/manifest.json` 格式、WXT 独立包路径或 SW 预算；不存在自动继承旧 CI 的验收结论。

1. 本地先检查 `git status --short --branch`、`git rev-parse HEAD`、`git rev-parse origin/main`、并行 Agent；安全时快进同步，不覆盖未提交修改。
2. 执行 `npm ci --ignore-scripts`、`npm run libs:check`、`npm run check`、`node --test tests/environment/libs-layout-r156.test.mjs tests/environment/fixed-entries-audit.test.mjs tests/environment/dev-service.test.mjs tests/environment/task-package-flow.test.mjs`。
3. 执行 `npm run build && npm run build:dev && npm run verify && npm test && npm run libs:doctor -- --strict && npm run build:size`，并对新候选执行包/ZIP 一致性核验；生产 SW 硬预算仍是 327680 bytes。
4. 根据测试复用指南，仅补受此目录变更影响的真实 Chrome Page USER_SCRIPT 与 Controller、Task 安装/验证、退权、重启等场景；必须保留实际候选、packageHash、原始回执与失败证据。
5. 网页会话无权接入用户本机工作树、Chrome Profile 或测试进程时，相应本机步骤记录为 `NOT_TESTED`；GitHub 源码提交不等于已完成真实本机验收，更不等于正式 F3/ZIP 交付。

历史文档中出现的旧路径是时间点证据，不应被批量篡改为当前路径；新开发只允许使用正式 `src/libs` 引用。旧库历史来源仍按 R15.5 的迁移矩阵另行管理，不把此目录整理冒充全部第三方库已迁移。
