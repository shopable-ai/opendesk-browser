## 最短手动体验

1. 在当前 CFT 的「扩展」打开「阅读目录」，点顶部「语言」。当前已经停留在此面板。
2. 在「此工具语言」选择「仅此工具：简体中文 / English / 日本語」，观察「当前生效」及保存提示，再关闭面板查看工具和网页目录。
3. 需要统一偏好时选「跟随 OpenDesk」，再调整上方默认语言；需要保持单个工具语言时选「仅此工具」。
4. 只有添加、补译或备份时展开「添加或管理语言包」；此处的目标选择不会切换工具。
