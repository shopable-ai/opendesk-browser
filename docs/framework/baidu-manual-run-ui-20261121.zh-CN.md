# 百度搜索「参数与运行」需求与验收（待定稿）

目标：在「我的 → 百度搜索：前三条自然网页结果 → 参数与运行」，用户填关键词后就能点「运行任务」，并在点击前知道本次会使用当前百度页还是新开标签页。需要保留当前页时，在同一张参数表单里操作一次。撤回此前「目的地旁更改 → 下拉框」方案及独立「运行位置」区域。本稿先供审查，未定稿前不改业务源码或重建候选。

## 用户看到的交互

任务说明建议改为：“输入关键词，搜索并返回前三条自然网页结果（不含广告）。有可用的当前百度页时优先使用该页，否则新开标签页。需要保留当前页时，可开启「总是新开标签页」。”这是手动面板的建议文案，暂不修改包内 Manifest。

- **搜索关键词**是首焦点；结果数量仍为 3。表单内用一条只读提示标明实际去向，如「本次使用当前百度页」或「本次将在新标签页打开百度首页」。使用指定网址时，提示改为「本次将在新标签页打开指定的百度网址」，输入旁能看到具体值。去向提示没有「更改」入口。
- **总是新开标签页**：默认关闭，表示「自动：优先用当前百度页，没有就新开」；打开表示「即使当前是百度页，也新开一页」，用于保留原页、搜索内容或现场。开关关掉不承诺强制使用当前页。入口是一行任务参数，切换后立即更新去向，仍只需点击一次「运行任务」。
- **执行时切到前台**：原脚本参数 `showExecutionTab`，默认开启。开启会切到执行页；关闭不会主动切换当前页或窗口，搜索仍继续。新页先由宿主在后台创建；已经在前台的当前百度页不会被强制移到后台。两项用独立标签与开关状态，分别回答「在哪一页搜索」和「要不要切过去看」。
- **起始网址（可选）**：只有用户主动开启「总是新开标签页」时，才在该参数下显示；自动回退直接用 `https://www.baidu.com/`，不要求再选择。留空用百度首页；填写时必须是无凭据的完整 HTTPS 网址，Origin 严格等于已批准的 `https://www.baidu.com`。站外、子域、HTTP、其他端口、含凭据、相对地址或解析失败均在点击前就近提示，运行时由原检查再次拦截。网址用于新页的首次加载，不改变关键词，也不增加网站授权。

| 用户情形 | 点「运行任务」后应当发生什么 |
| --- | --- |
| 有合适的当前百度页，未强制新开 | 在打开面板时确认的当前页执行；不创建新标签页。精确关键词结果页继续只读提取，其他可执行的同站页面按现有脚本搜索。 |
| 没有合适的当前页，未强制新开 | 确认目标不可用后预告回退；只在点击运行后经宿主新开一页并加载百度首页。恢复草稿里的备用网址不影响这条路径。 |
| 用户显式开启「总是新开标签页」 | 无论原页是否为百度，都只新开一页；原页不导航。留空用百度首页，填写有效网址则从该网址开始；填写无效网址时不运行。开关与填网址本身不启动。 |
| 用户关闭「执行时切到前台」 | 按前三行同样选页并搜索；不调用 `page.bringToFront()`，不主动改焦点。新开页在后台执行，需要用同一运行回执证明有搜索行为。 |

「合适」指本侧栏所属窗口当前选中的、可确认的顶层文档，网址的 Origin 精确匹配此次安装批准的百度站点。确认还在进行时显示检查状态，避免把暂未返回误判成需要新开。自动去向在打开时确定并告知：若已预告当前页，换标签（包括同源）、重载、窗口或 Document/完整网址变化后，阻止运行并提示“原百度页已变化。可重新打开参数，或开启「总是新开标签页」。”重新打开保留草稿并重新判断；自动回退也不在编辑中悄悄改投另一页。显式新开不绑定原页，切回自动时仍按本次打开的目标校验。开始派发后沿用原目标文档和脚本导航合同；任何失败、撤权或结果未知均不自动改投或重试。

继续显示本次结果或明确标记的「上次执行」。任务返回停止、安全验证、失败、回执未知时按真实状态显示，未完成不能显示成功。任务拥有的临时页仍走现有清理合同；不承诺运行后留在标签栏，也不关闭复用的原页。

## 参数归属、回读和版本

归类为 **已安装的 Controller Task 手动运行**。业务 owner 是 [百度任务目录](../../task-packs/baidu.search/)，React 参数表单负责呈现，TaskWorkbench 用现有受信任的点击准备目标，RunHost / Authority 再校验并执行。[Controller 合同](../api/controller.zh-CN.md#page--locator-最小用法)只给脚本操作已绑定的页；`page.bringToFront()`没有选页或开页能力。当前实现有借用当前顶层文档和在后台创建任务拥有页两条路径，复用即可。不得在 UI 或 Worker 直接调 Chrome 新开页，也不新增授权入口、浏览器能力或运行器。

**建议的最低改动合同**：由百度任务目录提供固定编译、仅用于「我的」手动运行的参数定义，和确切受信任任务版本显式绑定；字段暂名 `openInNewTab`（布尔，默认 `false`）与 `startUrl`（可选）。同一参数表单和「参数 JSON」都读取同一套有效值。TaskWorkbench 在真实「运行任务」点击时解析并冻结这两项，经原 RunHost / Authority 接口提交既有目标模式；传给 Worker 的参数仍按原 Manifest 严格校验，只包含 `query`、`limit`、`showExecutionTab`。不把当前位置/网址或新字段伪装为脚本的原有运行参数。这个定义是百度任务拥有的手动运行行为，不能适用到其他已安装任务，也不按显示名称、裸 Task ID 或目录来源赋信。匹配用于选用这一套手动表单，不影响任何已审阅旧包按原合同运行。

- 当前工作区[内置包 1.1.6](../../task-packs/baidu.search/releases/baidu.search.top3.v1.opendesk-task.json)的 `sourceUtf8` 与 [实际脚本](../../task-packs/baidu.search/src/baidu-search-top3.js)逐字节一致。其 Manifest 和 JS 都只接受原三项，`showExecutionTab`省略或为 `true`时会切前台，为 `false`时仍继续。旧版 1.1.5 的站内路径要求不同，保留通用入口。本地 `main` 的 HEAD 仍为 1.1.5，工作区中 1.1.6 的包与发行登记是已有变更；它们不证明当前浏览器已安装该版。
- 当前安装身份内，旧草稿和旧 JSON 照常回读：缺 `openInNewTab`按关闭；原关键词、固定数量和明确保存的 `showExecutionTab:false`原样保留。新开偏好跟随原窗口及准确安装身份的参数草稿，不是全局设置；窗口、标签、Document 及授权不能从草稿恢复。旧下拉框的临时选项和网址并未进入原参数草稿，不推断或迁移成新开偏好。
- 表单与 JSON 双向验收：关闭新开时，表单暂存已填写的备用网址但不把它带入本次运行 JSON；再开启时恢复输入并重新验证。JSON 显式提供非空 `startUrl`时必须同时是 `openInNewTab:true`；矛盾、拼写错误、错误类型或非法输入，保留原文并报错，不忽略、更不开页。不保存任何运行目标身份到参数 JSON。已有手动运行表单的保存/回读、模式切换和历史回执沿原所有权。
- 上述方案不改 1.1.6 的固定 Manifest、代码、双哈希或安装授权，也不改 Google、同名自定义任务、Web Flow 的保存与确认两步、网页交接、计划任务。如果产品要求新参数随独立任务包分发，则这将是另一项版本决策：新增不可变版本和新双哈希，走既有候选验证及安装审阅；在明确宿主支持、参数消费入口和只迁移有效业务草稿的规则前，不改固定包。旧版本、安装身份、权限、历史运行和未知回执不自动搬到新版本。

## 定稿后的最小测试与通过条件

| 用例 | 可观察的通过条件 |
| --- | --- |
| 320 / 360 / 400 CSS px | 真实侧栏打开即聚焦关键词，标题、去向和主操作清楚。开关各自单行，选中、焦点与两态可辨；无横向裁切、位置控件折行、第二套选择器或额外确认。长网址限制在输入可用区域，不撑宽表单。 |
| 键盘、读屏、中文输入法 | Tab 顺序符合阅读顺序，Space 切换开关，键盘可运行；Escape 关闭并回到原任务入口。读屏读出固定名称、开关状态、去向和网址错误；IME 合成中按 Enter 不提交，退出合成不丢关键词。键盘、实际读屏、IME 分别记证据。 |
| 四条核心路径 | 对照上表核验实际标签 ID、原页是否导航、打开次数、前台变化、关键词和结果。打开、切换开关、输入/编辑 JSON、保存或关闭时没有新页、RunHost 写入或搜索。真实点击只提交一次。 |
| 起始网址和回读 | 明确新开，从批准的非首页网址开始；以首个站点导航证据证明走了该网址，不能仅看最终百度搜索 URL。阻断站外及非法输入；清空回到首页；测试旧 JSON 省略字段、新 JSON 两种开关、草稿关闭重开、备用网址及矛盾 JSON。 |
| 目标竞争与安装保护 | 被预告的原页换站、同源切页、刷新或改址后阻断；再次打开核对新页后才能复用。权限等待、安装查验和实际派发之间重查；安装变化、撤权/权限不满足时无新页或后续网页动作。运行中按原围栏停止并准确记录。 |
| 重复与未知 | 双击、忙碌、原请求回执缺失不产生额外创建、搜索或提交。只能查询/处理对应原请求；不把 PENDING、脚本报告停止或安全验证当成功。原「上次执行」保持独立。 |
| 隔离原有消费者 | Google 和同名自定义任务仍用原通用运行入口；Web Flow 准备完成仍需单独确认；网页交接、计划任务及各自参数/权限合同不变。仅运行受影响保护和入口的定向回归。 |

先用定向验证证明表单、参数和目标连接；核心路径通后再冻结一个独立开发候选，在真实扩展 `SIDE_PANEL` 验证。不以普通浏览器标签页代替原生侧栏专项。为同一候选保存源码和构建身份、实际侧栏资源摘要、前后截图、回执和原生迹象。分列 Node、真实侧栏夹具、百度实站、键盘、实际读屏与 IME 的结果。实站三条自然结果必须有同候选真实回执；遇到百度安全验证或未知提交时记录并停止，不绕过、不自动重放。

独立五项评分：信息架构与文案 25、目标与脚本交互 25、键盘/可访问性/窄屏 20、授权与回归 20、证据可复查性 10。要宣布达标，须 **>95/100 且全部阻断用例通过**；无该候选证据标 `NOT_TESTED`；已失败的用例报告具体失败。当前不做 production 发布或全量矩阵。
