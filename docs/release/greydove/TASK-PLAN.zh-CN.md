# GrayDove（灰鸽）：品牌统一与 Chrome Web Store 上架任务链路

> 本文件是唯一的总体任务树。任务编号用于跨对话追踪；状态必须由证据驱动。路径是当前已知入口或待审计候选，不表示所有文件都必须修改。

## 1. 总体目标与发布边界

将现有 OpenDesk Browser 在不重构原有工程架构的前提下，完成 GrayDove（灰鸽）对外品牌统一，准备符合 Chrome Web Store 当前要求的商品资料和生产包，经过真实 Chrome 验收后提交审核。

2026-11-17 用户已确认：**首发只准备 Standard GrayDove；Developer 保留内部开发/验证发行。**

本轮不实现支付、订阅、会员、广告或应用市场分成。商业化只做独立规划。

## 2. 状态与证据规则

| 状态 | 含义 | 可否视为发布完成 |
|---|---|---|
| NOT_STARTED | 尚未开始 | 否 |
| IN_PROGRESS | 正在实施或审计 | 否 |
| BLOCKED | 存在已确认阻塞 | 否 |
| COMPLETED | 实施完成，未完成独立验收 | 否 |
| VERIFIED | 按明确验收标准独立验证 | 仅代表该任务通过 |

证据等级必须分开记录：

- SOURCE：源码或配置已修改
- COMPONENT：定向组件测试通过
- BUILD：指定候选构建通过
- PACKAGE：指定 ZIP 内容和哈希已核验
- CHROME：指定 ZIP 在真实 Chrome 安装和运行通过
- STORE_REVIEW：Google 审核通过
- PUBLISHED：用户可通过商店页面安装

较低等级不能自动升级为较高等级。商店审核和发布状态必须有开发者后台的实际记录。
