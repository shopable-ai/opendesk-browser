# GrayDove 扩展数据与安装恢复

阶段：本地开发。正式源码未接入账号服务；「扩展 → 更多 → 扩展数据与恢复」在无账号服务时明确说明不可用。验证用独立静态开发包、两个临时 Chrome Profile 和仅监听回环地址的合成账号服务。真实登录、远端同步与正式发布均未验证。「网页功能帮助」继续解释本机 Chrome 权限。

- **已安装扩展**是账号清单。明确保存时仅写扩展身份、名称、来源、版本、包摘要与启用状态。自动恢复开关按账号和浏览器 Profile 保存，默认关闭；登录本身不会为新 Profile 安装扩展。自动恢复只接收原账号保存的、已审阅且与本机内置官方目录精确匹配的可选包，并限于没有页面模块、后台、控制器、自定义菜单或敏感能力的包。已安装版本跳过；其余由现有正式安装入口或文件导入审阅。网站权限、Chrome 网页脚本开关、历史任务与凭据不随清单恢复。
- **扩展数据**与安装分开控制。当前仅接入 AI 知识问答中用户编写的问答库。首次备份需要确认把本机问答库关联到当前账号；之后从账号和已核验的安装包身份读取。恢复需要启用数据开关、通过工具自己的数据校验，且安装结果已核验。数据冲突时保留本机内容。Cookie、密码、令牌、网站内容和会话记录不接入。
- **删除有不同作用范围。** 本机卸载保留账号清单，并阻止本机自动重装；从账号移除只改清单。删除账号备份不会删除各设备已经保存的工具数据。安装沿用现有安装器的安装世代和回执；无法确认时只查原交易，不重新安装。更换账号会从界面撤下上一个账号的记录和已打开的问答库。

生产接入点是 `src/sidebar-tools/recovery/account.js`。后续真实账号适配器必须用已认证会话绑定快照读写和版本校验，切换账号隐退旧会话。不应将本地验证身份接入日常或正式构建。
