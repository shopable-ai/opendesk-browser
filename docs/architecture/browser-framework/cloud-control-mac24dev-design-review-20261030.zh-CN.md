- 评审方式：只读设计及本地相关源码，判断能否据此制定实施计划；远端后端事实采用主 Agent 已完成的 SSH 源码调查。评审者未运行测试、操作浏览器、SSH 访问远端或修改文件。
- 初审没有达标：正常 owned 标签页在释放前被关闭，事后人工读取 DOM 的验收安排不能稳定证明原执行效果。
- 修订：明确先准备原标准页的被动观察，在关闭前留证，关闭后核对持久记录；复用现有测试方法并补齐每次 submit 计数、原生目标／文档关联与事件持久化。不能执行绕过业务后端的整套直投驱动，不改冻结 Task，不延迟退休，缺证据记 INCONCLUSIVE，未知不重跑。
- 同时明确：Stop 不能撤回已经发出的网页异步效果；当前 demo 没有选择 controlProtocol:2；Run 前取消的 Run/Result/释放显示不适用，不能伪造回执。
