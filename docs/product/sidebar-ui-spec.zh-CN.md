# OpenDesk Browser Sidebar UI SPEC · R4（正式信息架构）

> 更新：2026-10-08。当前权威 UI SPEC；延续 R2 的任务卡片和运行历史交互，继承 R3 浅色视觉基准及现有主干三页签实现。

## 一、产品定位与导航

OpenDesk Browser 是独立 Chrome 扩展，普通用户运行已安装任务无需 Codex、Native Messaging、MCP 或外部服务。

Sidebar 保留三个**一级视图**，使用同一个 Side Panel 文档、同一个运行 Host 和同一任务数据源：

| 侧栏入口 | 主职责 | 不做的事 |
| --- | --- | --- |
| **我的任务** | 已安装任务卡片、站点匹配、参数、启动/停止、最近结果、卡片下面的历史 | 不用 select 下拉框代替任务工作台；不单独增设运行记录页签 |
| **发现** | 在本机**已安装任务**中按当前网站、关键词、全部、停用等条件检索；点击选中任务并回到“我的任务” | 不联网搜索、不浏览未安装脚本市场、不自动安装、不主动申请权限、不自动运行 |
| **开发** | 编辑 JavaScript、未保存草稿直接运行、运行结果、保存版本/加载版本、DOM 脚本高级试运行 | 不把保存当运行前置步骤；不创第二套执行器 |
| 顶部 **任务目录 ↗** | 打开扩展自己的完整页面，浏览本地任务包、任务详情、导入、明确安装、验证状态 | 不是 Sidebar 第四个页签，也不是未实现的在线 Marketplace |

**“发现”与“任务目录”必须清楚区分。** 发现是已安装资产的查找与选择，任务目录是新资产的导入/安装/发布流程；两者共享 `listTaskCatalog` / `installed`，无第二套数据模型。开发时不可因为旧 R3 原型只有两页签就删除当前已实现的“发现”。

## 二、我的任务：卡片内完成一次任务闭环

```text
Sidebar 固定品牌头部 / 任务目录入口
一级导航：我的任务 | 发现 | 开发
滚动内容区
  我的任务 · 已安装任务数
    卡片 A：图标 / 任务名称 / 简明用途 / 启用状态
      [被选中后在卡片下方直接展开]
      当前网站匹配与所需权限
      参数表单
      当前执行提示
      最近一次结果
      运行记录（可折叠）
        最近第 1 次：成功/失败/停止 → 展开结果
          技术信息 → 折叠 runId / 版本
        最近第 2 次：...
      次要管理（刷新 / 复制草稿 / 停用 / 卸载）
    卡片 B：标题摘要（未选中）
  空状态 → 明确引导任务目录
底部固定操作栏：运行任务 | 停止
```

- 点击卡片选择任务只改变 UI 观察，不触发 `Run`、权限或持久操作。
- 展开区与卡片是同一视图层级；历史**紧贴所属任务**，不要另设外部“最近运行”独立区。
- 展开区使用**现有** DOM 控件与监听器，移动节点但不重建 Form、RunHost、当前 Run 或持久结果。
- 任务参数属于运行中的用户输入；切换一级视图不丢草稿与参数。不同任务卡切换应尽量保留未提交参数，原则上以本地 UI 草稿缓存为宜，不能自动持久化为任务版本。
- URL 不匹配、权限不足、停用、正在运行、失败、停止、未知结果分别给出准确状态文字。 `runId`、hash、documentId 不在普通用户的标题层展示。
- 记录从 Controller durable snapshot 读取，先按当前已安装版本关联的 `scriptId` 过滤，再绑定每个 runId 的结果；异步迟到结果不覆盖新选中任务。默认最多显示最近 8 条，完整结果可展开。
- 当前任务已启动而用户切换“发现/开发”时，**其所属停止操作仍必须可用**，不能意外显示另一运行器。采用既有 `syncRunDock` 所有权切换；不得新增第二个 RunHost。
- 站点权限请求只能来自真实受信点击；Run click 内冻结 Current Page / revision / params，授权后重新验证 exact document；Running Target 与当前标签页变化分离。失败不自动对另一个网页重试。

## 三、发现：已安装资产的本地检索

- 搜索名称、用途、任务标识和声明适用站点（不读取网页内容用于搜索）；搜索关键字保留在一级页签切换期间。
- 初始筛选“当前网页”：仅在 CurrentPageTarget 是可运行 HTTP(S) 文档时，按精确 origin 匹配**已启用**安装任务；不按类似域名猜测、不回退过期网页。
- “全部已安装”：包含已启用、已停用但未卸载的任务；“已停用”单独筛选，点击后回到我的任务并解释不能运行。
- 任务检索条目展示名称、用途、站点范围及网站匹配/启停状态。长标题最多两行、长 origin 换行；搜索无匹配、当前网页不可用、没有任何安装任务有各自空状态。
- 点击条目将已安装任务标识传给**同一工作台选择状态**，导航回我的任务，不调用 run / permissions.request。
- 顶部“任务目录 ↗”及发现固定底部操作区均可打开完整目录；用户不得把“发现”误理解成 Marketplace。

## 四、开发：编辑器是主要工作空间

布局建议：

1. 当前网页可运行状态（仅摘要，精确文档详情折叠）。
2. 大尺寸 JS 编辑器：`async function main()`、`page`、`params` 及 `return`。
3. 当前执行状态、目标及最近结果和日志（尽量贴近编辑器）。
4. 可折叠参数 JSON；保持值和错误信息。
5. 可折叠的 DOM `USER_SCRIPT` 即时试运行（单次、只对当前精确文档、可选锁定的 jQuery）。
6. 保存版本、加载、候选制作、高级目标、独立 SDK、健康检查（折叠）。
7. 固定操作栏：**运行草稿**为主，**保存版本**为次，运行时保留拥有者的**停止**。

编辑草稿不自动保存；点击“运行草稿”使用那一刻的编辑器字节而不是旧 revision。保存与运行不互相依赖；编辑、切换任务或进入发现不应该隐式丢草稿。DOM page-script 预览的 USER_SCRIPT world 与普通 Controller `page` API 模式必须明确区分，不能把原型演示当作原生权限通过。

## 五、完整任务目录（非 Sidebar）

独立扩展标签页，提供搜索/筛选、目录卡片、右侧阅读式详情、权限及网站范围说明、准确版本、真实安装按钮、JSON/JS 导入入口。目录未接入云市场服务时，只可展示本机真实已有候选与安装记录，不显示假的星级评价、认证与在线作者。

点击安装前明确确认任务版本、origin、权限；只有已有受信 `Available` 才能真正调用 `installTask`。安装反馈留在目录页，避免导航到完整页隐藏的“我的任务”。成功后通过仅含“目录已改变”的 BroadcastChannel 通知已打开 Side Panel；Sidebar **必须重新查询真正的 Task Catalog**，不能信任广播数据本身。

## 六、视觉系统（R3 浅色基准）

| 设计决策 | 建议标准 |
| --- | --- |
| 主背景 / 内容 | #F5F7FB / #FFFFFF，避免 R3 早期深底+深字可读性问题 |
| 一级文字 / 次级 | #1B2C49 / #53647E，提示文本保持易读，文本遵守 WCAG 2.2 AA |
| 主交互 / 状态 | 主蓝 #365EDA；成功绿 #138263；错误红 #AE3D4B；警示琥珀 #92651A；不得只靠颜色说明 |
| 字级 | 视图标题 16–20px、任务标题 12–14px、正文 12–13px、辅助 11px；运行代码为等宽 12–13px |
| 间距 / 圆角 | 4px 网格；8/12/16/20px；卡片 12–14px、表单 8–10px；克制边框和阴影 |
| 滚动模型 | 品牌、三视图导航、运行操作栏固定；内容区独立滚动；长记录/代码内部适度滚动 |
| 主操作 | 运行按钮突出、停止始终可达；禁用必须附可理解的原因，不在窄侧栏放过多同权重按钮 |
| 任务卡片 | 未选中只展示名称/用途/状态，选中后展开同卡参数/结果/历史，不出现重复标题板块 |
| 发现页面 | 检索输入可见、筛选 chip 横向可滚，结果列表为轻量可点卡；不可安装按钮不得出现在这里 |
| 编辑器 | 至少 220px 初始高度，适配长代码，明亮代码区，焦点清楚；结果与代码间距尽量短 |

断点：300px 单列可见；360px 典型窄侧栏；420px 设计审查基准；520px 使用增加的宽度提高排版舒适度，而非增加第四列。字号放大、长错误、长任务标题、长网址和无历史记录均不得造成横向溢出或底部按钮遮挡。支持键盘 Tab/Enter/Space、`:focus-visible`、`label`、`aria-selected`、`aria-expanded`、`aria-live`、原生 `details/summary` 展开。

## 八、独立验收与证据分级

**组件／静态检查**：
- 三页签均存在且可以点击；“发现”只检索已安装，选择任务不发权限或 Run。
- 任务卡与详情/参数/结果/历史属于同一节点下的布局，历史每条可展开，技术标识藏在次级详情。
- 保存与运行独立，草稿不因切页丢失；RunHost owner Stop 跨页签仍可访问。
- 打开目录使用既有独立扩展页；成功安装不会跳到隐藏视图，Side Panel 通过 Catalog 再查询刷新。
- 原 DOM ID 未删除、未重复；最小定向测试：`node --test tests/environment/task-workbench.test.mjs tests/environment/sidebar-product-contract.test.mjs tests/environment/script-editor.test.mjs`；另运行 `npm run check` 及必要构建。

**Chrome/CFT 原生检查**：以真实受信点击和真实安装版本检查 300/360/420/520px、125%/200% 字体缩放、扩展完整目录、安装与侧栏同步、精确网页权限、Run/Stop、修改草稿后立即运行、重新打开面板后的状态。没有可追溯的真实浏览器回执写 `NATIVE_NOT_TESTED`；静态 HTML 和 Node tests 不是原生 PASS。

独立评分维度：视觉层次、交互完整性、开发体验、普通用户体验、无障碍和错误处理。分数只能基于明确证据给出；高风险执行归属与权限问题可直接阻断接受。
