## 1. 决策：交付可找回的结果，而非第二个提示词管理器

用户工作（JTBD）：「我刚在 ChatGPT 得到一张商品图，希望主动点击一次保存，将它以 SKU 标准文件名下载；以后输入 SKU 能追溯文件状态、来源和人工确认的提示词。」购买对象候选是经常输出 SKU 图片的电商设计师、运营人员，后续可能是团队负责人；频率、预算与付款意愿均待访谈。**用户主动采集**、可解释权限、保留文件本身、结果核对是价值假设；“能复用 SDK”不是销售证据。

- Prompt Shortcuts 仅存提示词、提供快捷插入；不升级为知识库。
- Knowledge Inbox 作为**唯一交付记录与搜索入口**；不能再建一个素材列表/储存系统。
- Web Markdown Clipper 继续负责普通网页 Markdown 剪藏。
- Browser SDK / Trusted Host 负责授权和下载；Native Workspace 的现有文件文本协议不扩写任意二进制。
- 产品默认免费本地首次成功；独立付费能力只作为待验证的外部交付、团队维护、业务对接，不预先成立 SaaS。

## 6. 唯一先行 MVP：AI 商品图片快捷交付

**承诺**：在受支持且已授权的 ChatGPT 图片旁，用户主动点一个保存图标；补必需的 SKU，选择主图/场景图/详情图和编号；预览规范文件名；下载**实际可靠识别的资源格式**；确认 Chrome 状态为 `complete`；交付结果写回既有知识记录；后来搜索 SKU 能找回**文件名、下载状态、时间、来源**。用户自行确定文件所在的浏览器下载目录；首版**不承诺任意本地目录写入**或 Finder 真正持久可解析路径。

交付记录中的 `success` 必须来自**完成状态回执**，`started` 不等于 `complete`；失败保留本地记录供查询与恢复；未知结果先核对而非盲目二次下载。缩略图/短期 URL 必须标识并阻止冒称原图。文件扩展名来源于可信 MIME/文件检测；若无法证明应拒绝假扩展而不是强制 `.png`。提示词仅在能可靠取回且用户确认后附加；否则写“未关联”。

### 免费获客和收费假设（尚无任何支付数据）

- **免费入口假设**：一张图主动保存，SKU 找回，少点操作，无需注册。
- **个人付费假设**：只在有可重复验证的省时/质量提升后测试高级规则或批处理便利，先访谈替代方案与预算。
- **团队付费假设**：一项确定的审核/文件交接/维护责任能让团队主管愿意签单，必须确认预算人、采购范围与数据边界；不在本轮开发云端协作。

### 可证伪实验 / STOP/PIVOT

先观察 10 位符合画像用户（预登记纳入条件），由对方在其自有/授权页面**无指导**独立保存并重新搜索：建议至少 7/10 完成；其中至少 5 人在两个自然工作周期再次主动使用，至少 2 人能指出与现有手工步骤相比要付费购买的具体结果及预算/采购决策人。**这些是事先提出的决策门，不是已发生的统计**。

- 安全来源无法稳定判断、原图真实性不能核对，或授权无法控制：**STOP**，不扩大上线。
- 用户无法独立完成，且失败不是可小幅修复的 UI 问题：**PIVOT** 到单一可审计的「SKU 命名下载」，停掉复杂管理界面。
- 自然重用不足或已有免费替代足够：**STOP 付费产品假设**，可保留免费工具。
- 无明确购买者、没有预算/签约动作：不建设团队 SaaS，不把口头兴趣转成收入。

### A.5 真实 MVP 边界、付费和 STOP 原则

目标用户：频繁处理 ChatGPT 商品图的电商设计师或内容运营。最小闭环：**已授权页面生成图旁用户主动点击 → 输入 SKU/选择主图、场景图或详情图 → 可信原图和真实 MIME 的安全文件名 → Chrome 下载状态核对为 complete → 将文件名、来源、标签、SKU 和结果写入既有 Knowledge Inbox → 重新打开并按 SKU 找回**。`started` 或 `downloadId` 不是下载完成；图片 URL、缩略图、WebP/JPEG 不得假装是永久原始 PNG。

分清三类不同的权限：**标准 Chrome 下载**、**用户主动授权目录的文件写入**、**Native Agent 或企业 API 写入**。首版不承诺普通插件能静默写入任意 Mac 路径。提示词「下次直接插入」归 Prompt Shortcuts，「收藏研究」归 Knowledge Inbox，不擅自双写，也不自动发送 AI 消息或上传私人对话。

免费获客假设为基础一次保存；个人付费可能尝试批量命名/预设规则，团队付费可能尝试审核清单/交付规范。原先提到的个人 $6/$12、团队 $39/$79/$149 仅是**潜在访谈报价锚点**，不是当前价格表、付款或已存在账户订阅。只有真实首次完成、跨自然工作周期自发复用、明确购买者/预算和可维护成本，才进入收费实验。

用户没有消费清单的真实证据前，**CSV/JSON 交付清单只作为紧随最小下载闭环的可选验证**，不是本轮已实现功能；DAM/PIM/CMS、n8n/Webhook、跨站批量爬取、Native 二进制写入、自动 AI 提取默认全部延后。不能用添加复杂功能掩盖无需求、原图失败或下载状态不可核对；依据本页正文的 `GO / PIVOT / STOP` 门槛处理。

后续执行顺序：**先维护这三份权威记录 → 核对原版同源预览并由用户确认 → 正式源码最小改动 → 真实 Mac Chrome 下载与读回证据 → 用户访谈/重复使用/付费试点**。在用户确认预览前不得将 MOCK 交付标为真实成功。
