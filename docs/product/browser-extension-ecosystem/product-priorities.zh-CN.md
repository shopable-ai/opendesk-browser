## 四、首批三个真实 MVP／生态切片

### 历史 MVP 1（DEPRECATED / 已停止）— Page QA Inspector

> 2026-10-12 产品结论：停止以 Page QA 作为首款商业插件或当前独立验收任务；已有源码只保留内部技术样例。尚无独立用户留存、付费或相对竞品差异化证据。
**故事**：“作为测试工程师，我访问测试站，点击扩展后，得到当前页面 DOM/可访问性问题列表，点击问题定位页面元素；不浏览其他标签、更不读取 Cookie。”  
- 最小范围：当前标签的 Locator 提示、标题/aria 标记检查、只读 JSON 报告和开关；其余能力不预置。复用 `src/framework/locator.js`、`src/platform/chrome`、`src/ui/design-tokens.css`，但 Browser SDK 未开放部分要通过自有可信 Host 重新验证。
- 合法权限：`activeTab`、`scripting` 和本地设置所需 `storage`；无 `<all_urls>` / `cookies` / `nativeMessaging`。
- 验收：一个产品一个 ZIP、与 OpenDesk 并装、不会共享数据、无闲置权限；真实 Chrome 20 次点击、导航/撤权/重启、无效页面拒绝；CWS 单一目的文本人工通过。
- 风险：和 DevTools/a11y 产品竞争强，产品差异尚待访谈；MVP 不加入网络改写。

### MVP 2 — Research Clip & Cite（OpenDesk 工具 + Page 脚本）
**故事**：“作为研究者，我在文章上选区并点击保存，重新打开时能看到文字、URL、时间、页面标题和引用，并可以导出，不联网也能用。”  
- 复用 `examples/sidebar-tools/reading-toc`、`quick-notes`、`web-markdown-clipper` 以及已安装 Page 身份/存储。
- 页内 UI 默认少量非侵入；用户动作才读取选区，读书笔记本地保存，远端同步必须明确 opt-in。
- 验收：10 篇不同结构的公开文章，覆盖 SPA/刷新、浏览器重启、禁止页面和撤权；本地恢复一致/引用可追溯、样式可关闭；维护风险中。

### MVP 3 — Script Publish & Upgrade Slice（C 生态基础链）
**故事**：“作为脚本作者，我修改同一个网站小脚本并发布 v2，用户能看到网站权限和代码差异，确认后升级；故障时回退 v1。”  
- 复用当前 `dependency-manager.js`、`installed-programs.js`、`page-component-preparer.js`、`src/marketplace/intent.js` 的授权原则，不再建第二个 Page Registry。
- 先仅精选脚本 5–10 个/人工签收；不同源和权限扩大必须再次确认，`GM_*` 未经兼容验收默认拒绝。
- 验收：真实 .user.js 安装、逐站启用/停用、更新哈希差异、断网、恶意依赖/撤销、CFT 真实来源回执、失败回滚。维护风险中高（网站 DOM/供应链）。
