# OpenDesk Browser R5.1：统一工具无 JavaScript 弹窗

- 阅读目录、网页剪藏、知识收件箱的网站授权／撤销由用户明确点击直接完成，不叠加 JS `confirm()`。
- 工具卸载只在详情页内显示确认区域，必须点击独立的“确认卸载并删除数据”；取消或工具身份变化均不执行。
- 工具已安装、启用／停用、站点授权、显示偏好是独立状态；不修改 R26 生命周期架构与执行限制。
- 工具更新保留版本、能力差异审阅，确认按钮是最终选择；不同来源的非官方包不能静默越权替换。
- 对未保存编辑，应用内部导航阻止意外丢弃并显示行内提示；取消 `beforeunload` 以避免 Chrome 离开确认框。直接关闭标签页可能丢失尚未保存的更改，必须提前保存。
- Native Workspace 知识草稿也改为行内保存／复制提示，不再通过模态框询问。
- 仍须遵守 Chrome 自身的权限授权提示和敏感能力运行检查，不绕过系统安全边界。

验收：对应源代码和真实 Chrome 须验证无工具 JS alert/confirm/prompt、无 beforeunload 模态、卸载取消／确认、跨窗口身份变化、站点权限恢复与 R26 启停行为。
