# 关于此扩展：版本、作者与网站

日期：2026-11-20。状态：产品设计与实施目标已定义，尚未完成产品验收。验收见[关键测试与专家评分](../framework/extension-about-test-plan.zh-CN.md)。

用户要能确认「当前安装的是哪一版」，并在信息确实存在时找到作者和开发者的网站。统一入口是 **扩展 → 对应条目的「更多」→「详情」→「关于此扩展」**。「更多 → 详情」是便于记忆的两步；打开详情后基本信息默认可见。无主操作的条目仍可点整行进入详情。已有「打开」的应用继续以打开为主，列表不新增常驻的作者、网址或版本列。

右上角的齿轮仍表示工具设置。先在至少一个已有框架设置且能保留当前工具状态的入口复用同一「关于此扩展」信息区；主入口不依赖齿轮。没有设置的网页增强不加空齿轮或空设置卡片。全局设置中的 OpenDesk Browser 版本是框架版本，不能填入单项扩展的版本；当前目标不增设全局菜单。

| 信息 | 必需性与显示规则 |
| --- | --- |
| 已安装版本 / 可安装版本 | 基本信息首行。已安装项显示本机已确认的版本；未安装候选明确标「可安装版本」。已有包格式要求的版本仍必填。历史记录只有修订号时显示「版本未记录」，另列「修订 r…」，不把修订号或当前目录的版本冒充已安装版本。可用更新仍走原审阅入口，可明确标示目标版本。 |
| 作者 | 可选，一个人或团队名称。自报作者按纯文本展示。作者缺失时隐藏整行，不从 ID、Git 提交者、安装来源或平台品牌推断。 |
| 发布者 | 可选，只有独立可信的发行证据能证明发布者身份时才显示「已验证发布者」。与自报作者、安装渠道含义不同；不重复显示同一名称，不因第一方名称或 ID 相同授予标记。 |
| 开发者网站 / 支持链接 | 网站可选，支持链接是独立可选字段。显示可辨认的目标域名并说明在新标签页打开。没提供、无效或重复的链接隐藏对应行；使用「开发者网站」这一中性称呼，不把自报链接标为「官网」或 OpenDesk 背书。无需平台管理员为每个扩展录入网站，也不显示私人联系方式。 |
| 安装来源 / 技术信息 | 保留现有本地、发行渠道、未知来源及权限和恢复语义。ID、修订号、摘要等放原「权限、版本与技术信息」或相应技术区，避免和首行重复。适用网站和安装来源都不能自动充当开发者网站。 |

普通应用、固定编译的可信应用、网页增强及其官方候选均由现有「扩展」详情提供统一呈现。对具有独立身份的 App + Page 组合，主版本属于父应用；需要诊断时才按「网页组件版本／修订」展示已确认的配套版本，且不能把候选或残留组件的版本填进去。Controller Task 属于既有任务目录，复用原有版本、作者和来源展示；不把任务迁入扩展列表，也不改写现有任务清单必填约束。

## 数据来源和实施边界

- **Sidebar Tool**：现有安装包的 `version` 已可读取。新增可选的作者配置建议沿用 `author`、`homepage`、`supportUrl`，在现有 `tool.config.json`、打包器、安装包校验、序列化与安装记录中一条链路传递。只有确实提供的字段才写入新包；不批量重打旧包。未填字段的历史包继续通过旧合同，规范序列化、摘要和安装身份不因读新版 UI 而改变。若严格旧客户端拒绝带新字段的新包，在兼容说明中标明最低客户端版本，不能靠忽略未知字段绕过包校验。
- **Page 网页增强**：安装包已含语义版本，但当前导入路径校验该版本后没有写入安装记录，扩展中心读取的主值是内部修订。方案是在现有冻结候选和安装链中，用同一已校验包或同一冻结源码绑定并保存展示信息。离线包以已校验包版本为准；直接冻结的 USER_SCRIPT 可通过现有解析器读取同一固定源码中的 `@version`、`@author`、`@homepage`（兼容 `@homepageURL`、`@website`）、`@supportURL`。不用当前目录、最近草稿、旧安装另一修订或未经校验的请求补齐。历史记录能从同一固定身份的既有证据恢复时可回读，否则保留诚实降级。
- **官方候选**：只展示现有可信候选描述中明确提供、且绑定该候选的信息；不为打开详情额外下载程序包或联系外部网站。已安装项能独立显示；目录离线、新版上架或来源未知都不改变其展示和使用。不拿目录的作者、网址和版本回填同名本地包。
- **呈现与导航**：在现有可信 React 详情中复用同一只读组件和本地化字符串，业务设置与沙箱 UI 继续归原项目。长文本可阅读、可选中、可换行，字段缺失不留空卡片。对外链接限长度、绝对 HTTPS、无凭据和控制字符，校验后展示规范域名，拒绝协议相对地址、浏览器内部、文件与可执行协议及伪装凭据。链接由真实用户点击打开，隔离 opener、不传来源、无预加载；显示和点击均不授予网站权限或启动业务。

该工作归通用框架展示及其现有包/安装记录 owner；无需公开 SDK 增加权限 API，无需每个沙箱项目实现一次「关于」。复用[扩展详情 React](../../src/ui/react/tabs/tools.tsx)、[扩展中心数据投影](../../src/ui/extension-center-model.js)、[Sidebar Tool 安装包契约](../../src/ui/sidebar-tools/package.js)和 [Page 安装记录](../../src/scripting/user-scripts/installed-programs.js)。先打通真实详情中的已安装版本及旧记录降级，再完成可选字段从配置到展示、已有框架设置的复用，以及同候选正式验收。若并行变更碰到同一详情或安装契约，先核对重叠并保留原行为，独立事项继续推进。
