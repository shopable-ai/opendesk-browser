# AI 回复思维导图错误经验

## 当前完成标准：三个真实站点通过关键 UI 回归

使用用户实际使用的浏览器和原生 OpenDesk 侧栏。先核对加载方式、实际安装的程序 ID、修订和源码摘要，以及站点授权、匹配注册和当前顶层文档是否运行；打开后再核对 XMind 子框架的归属。整个矩阵使用同一候选、同一负责网页的程序身份，旧版和另一安装身份的结果不得混用。

| 真实站点 | 样本 | 每条回复 |
| --- | --- | --- |
| DeepSeek | 两个现有会话中四条已完成回复（3 + 1） | 两轮 |
| ChatGPT | 最新、历史各一条已完成回复 | 两轮 |
| Gemini | 最新、历史各一条已完成回复 | 两轮 |

1. 刷新或切换对话后，在该回复的原生操作行确认只有一个可见、能点击的导图按钮。回复未挂载时先用实际滚动找到它；回复已挂载但没有按钮，记为失败并检查程序有没有进入当前文档。
2. 实点按钮，确认 XMind 节点来自该条回复。节点渲染后至少持续显示两秒，期间没有闪退；实点缩放，核对画布比例确实改变。
3. 点「返回原文」，确认同一条回复恢复可见且位置可用。从同一个入口重开，重复核对。无需发送新消息。
4. 按站点、样本和轮次保存脱敏回执及可查看的网页证据，不记录私人会话 URL 或原文。每条回执绑定实际安装的程序 ID、修订、源码摘要，以及当前顶层文档和导图子框架的归属。区分未运行、按钮缺失或重复、打开异常和关闭恢复异常。八条回复共十六轮，全部通过才算完成；本地测试只证明预检行为。

本轮候选尚未安装，三站实装回归通过 0/16。当前最早的已证实失败是旧安装在两个真实 DeepSeek 会话中刷新后没有按钮，也没有该文档的导图程序运行记录。ChatGPT 和 Gemini 本轮尚无实装回执；旧版本或本地页面的通过记录不能计入。

实页回归驱动要求先填写本轮候选的程序身份及实际浏览器的扩展 ID，并指定同一安装所属的诊断标签页。每次打开后，在画布仍可见时把实际子文档和 XMind 执行回执对应起来。如果预期程序确实进入了顶层文档、但画布由另一个安装创建，该轮仍失败。诊断只读，回执不保留文档标识或对话地址。

## 2026-11-24：DeepSeek 打开闪退，ChatGPT 关闭后历史回复离开页面

这两种现象都与打开或关闭导图时切换回复界面有关，触发条件不同。先辨认是导图在**打开时自行消失**，还是用户**关闭后找不到同一条原文**。

| 场景 | 已确认的问题 | 修复及保留的行为 |
| --- | --- | --- |
| DeepSeek 已完成回复：点击后出现黑框，随后自动退出 | 已完成的回复仍可能在打开后局部重绘。旧逻辑把正文变化后的 700 ms 稳定等待和实际生成共用一个退役条件，导致仍然有效的画布被立即关闭。 | 同一完成回复的局部变化只把已打开的快照标为待更新；新的快照仍要等正文稳定。实际重新生成、回复身份变化或离开对话仍清理旧导图。 |
| ChatGPT 历史长回复：导图可打开和缩放，点返回后偶尔只剩最新回复 | 旧关闭逻辑等 XMind 子框架完成异步清理才恢复滚动位置。此时原文和画布的高度已经变化，ChatGPT 可能先重新定位滚动并卸载历史回复。旧版真实页面观察到一次，后续两轮没有复现；延迟清理的时序缺陷在定向测试中可重复验证。 | 关闭时先隐藏画布、恢复同一原文、焦点和滚动位置，再等待子框架清理。真实页面上其他历史回复异常仍须分别确认。 |

如果点击后原文已恢复且出现提示，优先检查控制台的 `[OpenDesk ChatGPT Mindmap]` 记录中的阶段、错误码和运行修订。两个站点使用同一日志前缀。若 `Extension context invalidated` 出现在错误信息里，说明当前页的扩展上下文已失效，应刷新该页再试。其他启动错误恢复原文后允许重试。若点击没有进入目标按钮的事件路径，先检查滚动后按钮是否还存在、是否被遮挡，不能据此判定 XMind 启动失败。

如果页面根本没有按钮，先确认回复已完成，再在目标标签页刷新一次，同时检查新顶层文档上的触发器数量和程序运行记录。站点权限有效、存在匹配注册，只能说明具备部分运行条件。旧安装上两个真实 DeepSeek 会话刷新后分别有 3 条和 1 条已完成回复，但按钮和对应文档的导图程序记录都为 0；这次未进入导图打开流程，不能拿来判断黑框闪退是否已修复。先核对实际安装的程序身份、修订、源码摘要及新文档的运行记录；等到按钮出现并确实进入打开阶段，再排查 XMind 子框架和导图生命周期。

当时的本地回归覆盖 DeepSeek 四条已完成回复、ChatGPT 最新和历史回复；真站以文首的三站矩阵为准。

- [浏览器回归驱动](tests/reply-mindmap-ui.ego.js)支持三个内置站点。[本地页面样例](tests/serve-deepseek-ui.mjs)使用实际视图和 XMind：DeepSeek 四条、ChatGPT 两条各连续两轮通过；另验证 DeepSeek 启动失败可恢复原文并重试。
- [关闭时序及失败回归](tests/xmind-answer-registry-lifecycle.test.mjs)覆盖子框架尚未清理时原文、焦点和滚动已恢复，以及旧画布的异步错误不会关闭新画布。相关定向 Node 测试 109 项通过。
