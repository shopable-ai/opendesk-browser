## 原始产品目标（不能漂移）
进入视频播放页 → 识别当前平台、片名、分集 → 提供真实可用且获授权的观看能力和故障恢复 → 如有授权/合同才提供备用供给 → 未来合法会员优惠、家庭席位与商业合作转化。
独立 OpenDesk Sidebar Tool；projects/video-svip/ 唯一业务源；不另做浏览器 Runtime 或平行安装器。

## 实用核心：只抽象技术机制，不复制源码
A. SiteAdapter：站点注册表（host + path + selector priority + episode rules + capabilities）；按 active Document 核实。
B. VideoContext：{siteId, canonicalPageUrl, displayTitle, titleSource, titleConfidence, episode, episodeConfidence, documentEpoch}。URL 仅本机临时保存，不上报。
C. TitleResolver：先站点可验证选择器，再 meta/页面标题；异步稳定期有严格上限，识别失败为明确状态。
D. EpisodeResolver：优先经过验证的当前集标记，其次 URL/DOM，无法区分“当前集”和“总集数”时返回 unknown，禁止伪准确。
E. TaskController：单次意图唯一 operationId，AbortController 取消旧任务；navigation/revoke/stop 即失效，旧结果不得刷新 UI。
F. VideoHealth：经现有可信 Host 的只读、限量检测 HTML5 video 的 paused/readyState/error 等；检测状态不等于实际“已获得会员播放权限”，需要二次独立核验。
G. AuthorizedSourceAdapter（未来）：仅签约合法源/官方播放方式，sourceId 稳定、允许列表、timeout、健康度、断路器、来源审批与快速回退。
H. ProductUI：主视图“当前视频→官方观看/诊断→明确失败处理”；次级“会员”；合作入口无真实渠道时禁用。

## 关键技术风险与反方审计
1. 原脚本通过第三方解析绕过会员限制：稳定性、合法性、资源真实性、隐私与平台条款均不可控；不要把解析入口原样复制或包装成可售后服务。
2. 外部 iframe、站点 URL 查询参数外发可能泄露浏览信息；外部代码/接口未通过来源审查时不能获得用户 Cookie/令牌。
3. 原生 HTMLMediaElement.prototype.play 被覆写，500ms 轮询可造成播放器损坏、静音/重复播放和残留；完全不继承。
4. 站点选择器易随 SPA 和 AB 实验变化；限定匹配范围、保留诊断证据、使用 timeout/epoch 防旧文档误识别。
5. 不以“解析 iframe 加载成功”代替首帧播放或持续播放成功；区分识别、授权、可播放、首帧、连续播放几个状态。
6. 后备“自有会员账号池”不可作为默认供给：不得共享/出售个人会员账号、Cookie 或会话；只考虑服务方授权席位/票券/渠道/API。
7. GPL-3.0：上游 README 和脚本头声明 GPL-3.0，仓库未发现独立 LICENSE 文件；实施采用独立设计，严禁直接拷贝 GPL 源码；如决定复制，先由许可证专项评审并履约，不能把商业分销当作自动获得内容版权。

## 分级结论
- 可优先实现（P1）：站点识别、片名与集数、SPA 导航取消、播放状态只读、错误状态 UI、独立读回。
- 需要合法授权/后端与服务合同（P2）：多来源播放、健康 SLA/熔断、会员购买、家庭席位、分销推广。
- 不迁入：任何 DRM/登录/付费校验绕过、未授权解析接口、原站媒体劫持与全站静音、账号池 Cookie 共享。
