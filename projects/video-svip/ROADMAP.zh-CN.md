# 视频会员 · Video SVIP 差量路线图（R0.4A 起）

## 不漂移的产品目标

唯一产品 `video-svip`；唯一正式业务源 `projects/video-svip/`。用户打开视频网站 → 准确识别作品及当前集 → 找到合法观看方式 → 推荐合适来源 → 在有权控制且可观测的播放器中安全恢复 → 减少操作和不必要的新会员费用。

**四种不同事实：** 官方页面能打开、渠道被准入、用户权益已核验、实际媒体加载、视频确实播放。彼此不能替代。手工到期日永远只是 `SELF_REPORTED`。

## 后续单向里程碑（本轮仅保留规划）

**R0.4B — 正式来源选择与故障可观测。** 先确认 R0.4A Node/Build 和授权测试媒体的真实 Chrome 点击播放、失败回退与取消；再优化来源切换 UX、故障原因、手动恢复、播放后的状态独立读回。无合作协议时依旧只展示原站合法入口。

**R0.5 — 跨平台找片和会员成本决策。** 建立作品 ID / 版本 / 季集映射、合法渠道发现、观影清单和续看、会员组合成本计算与价格来源证据。TMDB 主要是作品元数据；Watchmode/JustWatch 等的渠道结果需核实地域、商业使用条款与实际权益，绝不把搜索到播放渠道等同可控制其播放器。不得猜会员价格或利用手工会员日期验证权益。

**R0.6 — GitHub 代码完成后的本地 Codex/RunHost/Mac Chrome 验收。** 和 R0.3.1 已在本地进行的腾讯、B 站识别任务去重；分开 `NODE / BUILD / PREVIEW / CHROMIUM / REAL RUNHOST / MAC_CHROME / REAL_SITE / AUTHORIZED_PLAYBACK` 证据，不能用 Fixture 冒充实站。

**R1.x — 有合同才商业化。** 合法会员推广、官方分销、正式授权媒体供应商、合规家庭权益管理、购买/售后/退款与真实转化指标。未签约的来源不允许出现在可执行播放候选中。

**远期可选、不得提前实施。** 自有媒体库、公开授权缓存、跨设备播放、经用户同意的受控 P2P/NAT 穿透和远程媒体节点。需要完成媒体权属、节点鉴权、带宽/隐私、审计、撤销与反滥用设计；不复制、缓存、分发他人的受保护付费视频。
