# 视频会员 SVIP · 差量路线图 R0.2（仅一个产品）

## 身份与产品约束
名称：视频会员；内部/正式 ID：video-svip；唯一源码：projects/video-svip/。
原始用户目标：在视频页面方便地观看、定位当前集、处理播放失败；后期通过获得授权的会员及备用资源提供可靠服务，并以真实合作权益作为商业入口。
设计原则：用户任务优先，核心播放辅助优先；只实现实用功能，不做平行 UI、不重建 Host/RunHost、只动最新 main、禁止虚假 PASS。

## 当前基础（R0.1.1，改名前）
原 video-pass 已实现：5 平台 URL/标题识别、打开原站、分享清理后的页面链接、手工会员日期本机保存/删除，双 Tab 侧栏预览与静态合同测试。
缺失：真正的当前剧集/影片实体识别，播放器状态独立读回，失败根因分类，多设备授权、正式授权播放/备用线路、支付与分享。
注意：源码存在不代表 NODE/BUILD/MAC_CHROME 已通过；不得推断已部署或无旧安装。

## 六环节按价值排序
| 环节 | 阶段 | 用户可见成功条件 |
| --- | --- | --- |
| ① 视频识别 | P1 首先 | 活动网页正确识别平台、作品与当前集；SPA 切页不串旧数据，缺失标 unknown |
| ② 观看与诊断 | P1 第二 | 原站观看始终可用；只读显示可确认的视频状态、错误和建议，绝不干扰平台播放 |
| ③ 异常恢复 | P1 第三 | 错误分类/重试可理解、用户 Stop 有效、无错误自动重复操作 |
| ④ 授权多来源 | P2 须授权 | 真实来源审核、权限、断路器与回退；首帧/15s 成功率基于真实测量 |
| ⑤ 会员/好友 | P2 须授权 | 仅合法官方权益、家庭席位邀请，不共享密码/Cookie；真实身份与到期核验 |
| ⑥ 商业转化 | P2 须合同 | 官方会员渠道和明确标注合作关系；下单/退款/服务说明真实可追溯 |

## 下一个最小技术里程碑 R0.3（只做 P1 第一环节）
输入：活动视频页，站点白名单，真实 URL/DOM 与当前浏览器 documentId。
输出：{siteId,title,titleSource,titleConfidence,episode,episodeConfidence,documentEpoch,recognitionState}。
行为：站点适配器→有界 title resolver→episode resolver→可信宿主核验→独立读回→紧凑 React/Sidebar UI。
不实现播放劫持、解析接口、会员购买和后台账号池；页内容不可交给模型执行任意脚本。
测试：Fixture 不少于 5 平台正常页、SPA 切集、同名作品、无集数、无 video、iframe/权限拒绝；原生 UI 未受影响。
实站验收：Mac Chrome 逐站读回，不能把 Node/Chromium 当成 Mac Chrome。

## R0.4 播放健康及恢复
沿用已有 video-speed-controller 的可信 documentId + ISOLATED 固定函数模式，独立审核是否需要新只读能力；不要滥用 page.videoSpeed 的设置权限。
分开“网页识别成功 / 播放器检测成功 / 账号有权观看 / 实际首帧成功 / 稳定播放”。
取消旧检测、限量 DOM 读取、权限撤回时拒绝读写；开关最小授权，无空白拦截页面。

## R0.5 UI 交互/真实用户测试
先在对话中提交可交互 HTML，保持与 projects/video-svip/preview/index.html 同源；只改真实 src UI。
320/360/400/440/520px、200% 缩放、明暗色、键盘/触控；icon-only，左右边距与间距一致，错误直接可操作。
非订阅站点和不支持的站点也能正确提供官方入口/帮助，不应把“识别失败”伪装成“会员已过期”。

## R1.x 授权运营服务（独立准入）
无版权/平台合同 ⇒ 仅展示“未开放/不支持”，禁止接入第三方 VIP 解析。
签约后：SourceRegistry(sourceId稳定)+BackendAdapter+health monitor（按来源/平台/设备维度计算真实首次成功率、连续 15s 成功率、失败率、回退成功率），明确试用/购买/退款边界。
禁止伪造 90%/99% 可用率；“100 个视频中 10 次失败”只是待验证场景假设。

## 质量与评分规则
多专家独立打分：用户理解、核心功能正确、架构边界、兼容/恢复、UI、权限与数据安全、测试可验证、商业合规；每维以 100 分计，综合取算术平均，不能累加，也不能用文案评分冒充测试 PASS。
R0.2 只做身份收敛、上游技术提取与路线图；R0.3 后才实现播放器识别增强，按完成/未完成/下一步报告。
