# Video SVIP R0.4A · 真实证据与未验收项（2026-10-30）

## 目的与保护边界

用户打开合法视频网站，先由原有官方 Host 识别作品/集数，再以获授权来源和严格证据做决策，用户点击自有测试视频后验证媒体事件、失败回退与停止。不得把官方链接打开、HTTP 200、iframe onload、Node stub 当成播放成功；不得修改、静音、劫持第三方原站视频或 DRM。唯一业务目录 `projects/video-svip/`，正式版配置仍为 `0.3.0`，新 R0.4A 是 GitHub 源码候选。

## 本轮实际修改

- `src/main.js`：来源身份/授权排序/最多 1 次故障回退、user-gesture 保护、自有播放器播放事件 + `currentTime` / 视频帧检查、读回、Stop/SPA/关闭代际取消。本次业务函数只有正式这一份，不复制解析器。
- `src/index.html`、`src/style.css`、`preview/index.html`：观看区、折叠候选、实际自有 `video` 与演示场景；预览里保留与正式 HTML 完全相同的主结构，加载同一 JS 和 CSS。
- `tests/environment/video-svip-source-r04a.test.mjs`：10 个 Node 定向单元/合同测试，**已提交但未执行为 Node PASS**。
- `.github/workflows/video-svip-r04a.yml`：main push 的定向 Node + build 接线；检查时未发现可确认的运行结果，不能虚报 Actions PASS。
- `README.zh-CN.md`、`ROADMAP.zh-CN.md`：更新当前实现、未来里程碑和证据边界。

## 复现命令与真正的 Demo 条件

```sh
node --test tests/environment/video-svip.test.mjs tests/environment/video-svip-ui-r03.test.mjs tests/environment/video-svip-source-r04a.test.mjs
npm run build:sidebar-tool -- projects/video-svip
npm run build:dev
python3 -m http.server 8765 --bind 127.0.0.1 --directory .
# Chrome 中打开 http://127.0.0.1:8765/projects/video-svip/preview/index.html
```

选择「R0.4A · 授权播放 / 真实媒体播放」→ 点击「播放授权测试媒体」，需观察自有 HTML5 video 的 `playing`、`timeupdate`、`videoWidth`、`currentTime`，记录任务版本与独立读回。再切换「失败→备用媒体」与「全部失败」「未授权」「地区不符」「无权益」「iframe 不可观测」，覆盖 Stop 和页面切换。自动备用播放若被浏览器拦截，必须明确输出 `NEEDS_USER_ACTION` 并由用户再次点击，不得视为通过。

**唯一当前验收阻断：** 缺少最新提交上的 Node/Build 退出码以及真实浏览器授权媒体事件证据。在得到这些事实之前不宣称 R0.4A 完成验收，也不直接安排 R0.4B 的完整功能扩张或本地 Codex 重复实现。
