应用结果模拟

应用与验证是两个独立步骤；即使应用返回成功，也不能直接展示「全部一致」。

运行期间异常

执行回执未知、目标失效与撤权都必须保守处理。不得自动重试或将恢复请求等同恢复成功。

能力与权限说明
本产品方向是「环境配置 / 应用 / 独立验证 / 恢复」。正式实现必须建立受信宿主能力和 Chrome 授权；Side Panel 不能通过本身的 navigator 伪装目标网页。

User-Agent、语言、时区、地理位置、视口属有限环境模拟候选；网络代理与独立 Chrome Profile 不等于更换一个预设。不能承诺防关联或完整身份隔离。
