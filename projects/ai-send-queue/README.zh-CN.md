**原始目标：** 用户在 ChatGPT 正在回复时预先编写多条消息，由唯一 Page USER_SCRIPT 队列依 FIFO 顺序在原生输入安全、原生消息入站确认后自动发送下一条；侧栏只检查网页状态并提供使用提示，不显示或读取队列数据。扩展中心要以一个独立应用完成 Page + Sidebar 的安装、打开、更新、停用、卸载，授权安全边界不合并。
