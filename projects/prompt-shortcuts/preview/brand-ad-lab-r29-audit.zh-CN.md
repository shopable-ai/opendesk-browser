# Prompt Shortcuts R2.9 · 离线广告实验室政策与商业评审

本文件只记录预览原型范围，**不授权在真实网页注入广告**，也不将静态测试等同于真实浏览器 PASS。

## 按序体验

1. 广告形式：品牌 3、赞助 5、卡片 4、商业 5，共 17 个 HTML 样式。选择后查看尺寸、窄屏、关闭、商业目的和风险。
2. 35 个定位：B01–B08、S01–S08、N01–N12、C01–C07。查看三语名称、锚点、兼容形式、UX、截图、窄屏、内容混淆和上架审查建议。
3. 虚构目标网页：新对话、短对话、长对话，支持选择、关闭、恢复热区；不访问任何真实第三方网页。
4. 侧边栏：0/1/2/3 已售卡；未售招商虚线只在招商预览显示，普通用户看不到。
5. Logo 与提示词：品牌永远在快捷栏顶部，0–4 个提示词，最多 1 个可独立关闭的赞助图标；插入草稿而非自动发送。

## 三种优先探索的商业组合

| 组合 | 位置 | 合作方式 | 核心理由 |
|---|---|---|---|
| 常驻 Logo + 单广告卡 | B01/B02 + S01 | 包月赞助 | 来源清晰、干扰较低、提示词列表优先 |
| 常驻 Logo + 极简赞助 | B01 + B03 | 固定位置合作 | 截图带出品牌；赞助图标明确区别于提示词并可关闭 |
| 多客户侧栏 | B01 + S02 | 位置与周期合作 | 最多三张按真实售出数展示，未售库存仅招商模式可见 |

**不建议进入正式产品：**N/C 全部网页广告候选，尤其 C06 消息之间的广告位置。N03/N04/N05/N08 可仅保留模拟截图比较，不能把网页留白视为可投放授权。

## Chrome Web Store 四类空间与审批边界

- **A 自有 UI 内赞助：**侧边栏 S 组可进行专门评审。明显标注、用户可关闭、列表和保存优先，并非天然通过审批。
- **B 品牌署名与自推广：**B01/B02/B08 不计入赞助库存，不得假冒目标网站。
- **C 第三方网页旁的扩展覆盖 UI：**必须额外确认来源披露、不干扰网页功能、不会模仿第三方网站内容；当前仅风险模拟。
- **D 在第三方页面内容中插入广告：**本轮禁止实施；N/C 所有候选均不触及真实网页。

官方政策：
- https://developer.chrome.com/docs/webstore/program-policies/ads
- https://developer.chrome.com/docs/webstore/program-policies/quality-guidelines
- https://developer.chrome.com/docs/webstore/program-policies/affiliate-ads

广告政策涉及明确关联、可移除、不得模拟通知、不得影响原有网站广告或功能。质量指南要求扩展遵守单一用途原则，对广告主导的扩展和向网页注入广告有警告。联盟合作必须充分披露，并要求与核心功能相关的直接透明用户收益及关联操作；此原型不注入联盟链接、Cookie 或跟踪参数。

初期可研究包月赞助和固定位置。CPM 需要可靠曝光和隐私评估；CPC 涉及点击归因，CPA 涉及转化归因。**不虚构广告主、流量、点击率、收入或政策批准情况。**

## 验收与风险

- 静态审查：JS 语法、17 形式、35 位置、语言、真实源码引用、安全 API、关闭与恢复逻辑。
- 真实浏览器：在安装 Playwright 与 Chromium 的环境中，运行 node --test examples/sidebar-tools/prompt-shortcuts/preview/brand-ad-lab-r28.test.mjs examples/sidebar-tools/prompt-shortcuts/preview/brand-ad-lab-r29.test.mjs。
- 如果浏览器测试没有真正运行，必须标记 NOT_TESTED；不得声称键盘、触屏、窄屏、200% 缩放和场景切换已经 PASS。
- 95+ 为每一维独立产品目标，不是开发自评分；有未闭环 P0 或缺浏览器证据时不应宣称已达成。
