AI Proxy 同源离线预览

在仓库根运行 node projects/ai-proxy/scripts/stage-preview.mjs --serve，打开 可交互同源预览。该命令直接编译 UI 源码，无需 Browser 构建、正式安装包或可信挂载；已有该服务时直接复用。

原版对照：先运行 node projects/ai-proxy/scripts/reference-preview.mjs，再打开 四种状态逐屏对照。原工作树只读；两侧仅使用内存数据。

省略 --serve 生成不可变离线快照及来源清单。

打开最新已生成预览（仅 SDK / storage 内存模拟，无真实网络、Chrome 或持久存储）。

历史原型保留于 legacy-ai-proxy.html，与当前同源预览分别记录。
