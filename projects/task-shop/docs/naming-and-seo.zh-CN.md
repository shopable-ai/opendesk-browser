# OpenDesk Task Shop · 命名与 SEO 决策

> 2026-11-02 初版。**品牌方案已选定用于项目文档；商标、域名、实际 SEO 效果和独立专家评分均未验证。**

## 1. 决策与命名层次

| 层次 | 采用名称 | 原因 |
| --- | --- | --- |
| 英文产品显示名 | **OpenDesk Task Shop** | 母品牌 + 易理解的任务市场概念 |
| 中文显示名 | **OpenDesk 自动化任务市场** | 直接说明任务领取、托管和本地执行 |
| GitHub 项目目录 | `projects/task-shop/` | 短、可读、不与框架层混淆 |
| 产品类别说明 | Automation Task Marketplace | SEO 文案用通用检索词，不当作唯一商标 |
| 技术架构概念 | Distributed Automation Execution Network | 仅作为架构描述，不取代用户产品名 |
| 固定文档检索词 | `OD-TASK-SHOP` | 新对话精确查找，避免与 Web Flow 混淆 |

**不再使用 `task-network` 作为本产品目录或面向普通用户的主名称**。`task-network` 可作为未来多节点执行能力的通用技术描述。脚本商店与付费任务市场在导航中分开，不因名为 Shop 就误导用户以为只卖脚本。

## 2. 当前竞品与命名冲突

- 已确认存在 [Taskmarket](https://taskmarket.dev/) 经营 AI agent 任务发布、接单、验收和资金结算市场（2026-11-02 浏览其官网）。`task-market`/`taskmarket` 不是具有明显差异化的独占品牌。
- `task-shop` 也是普通英语组合词；**不等于已经查明无同名公司/商标**。现阶段通过加上 `OpenDesk` 母品牌降低歧义，不代表可独占。
- 发布域名、商标类别、应用商店/社交账号同名、跨语言负面联想、各地区竞争状况**未完成正式检索**。未核实不得用“可注册”“全球唯一”宣称。

## 3. SEO 结构建议（尚未上线）

用户 SEO 搜索意图包含“自动化任务”“自动化接单”“浏览器自动化工具”“采购信息整理”“商品数据整理”“workflow automation marketplace”等，不因把关键字写进源码目录就自动提升搜索排名。

推荐公开信息架构，最终 URL 以审核后的实际域名为准：

| 页面路径 | 主要搜索意图 | 页面目标 |
| --- | --- | --- |
| `/tasks/` | 自动化任务市场、任务领取 | 解释任务模式、任务类型、筛选 |
| `/tasks/ecommerce/` | 电商商品整理自动化 | 可索引的类别说明与真实案例 |
| `/tasks/data-processing/` | 数据处理自动化任务 | 场景、工具、交付标准 |
| `/scripts/` | 自动化脚本、任务脚本市场 | 脚本安装与权限说明 |
| `/publish/` | 发布自动化任务 | 需求方价值与发布指引 |
| `/earn/` | 自动接单、托管自动化任务 | 节点主的参与条件与风险 |
| `/docs/` | 接单规范、授权与常见问题 | 解决疑虑、提升可信度 |

实践：描述性短 URL、小写、连字符分词、唯一标题、服务端可抓取的公开信息、规范化 canonical、内部链接、按任务类型实质内容建立页面。**私有任务、含个人信息的执行结果、支付/账户页不应索引**；禁止为了 SEO 自动生成大量无价值的模板页。

Google 官方建议：
- [网址结构最佳实践](https://developers.google.com/search/docs/crawling-indexing/url-structure?hl=zh-cn)：结构可理解、短、用连字符而非下划线；
- [Site Names in Google Search](https://developers.google.com/search/docs/appearance/site-names)：名称简洁、独特且一致；`WebSite` 站点名称以**域/子域级**识别，**不能为网站的子目录分别指定独立 site name**。如果与主站同域名子目录，站点名方案需与主站整体品牌协调。

示例标题（不是已上线页面）：`自动化任务市场｜领取、托管和执行任务 - OpenDesk Task Shop`。禁止承诺“轻松挂机日赚”“一键群发无限客户”等未验证或可能违规营销文案。

## 4. 关于“95 分以上”

先前提及的 **96/100 是对组合命名方案的主观设计目标**，不是经过用户实验、商标排查、SEO 数据和独立专家复核的客观评分。当前状态标记为 **`NOT_SCORED`**；不通过人为调高分数保证过线。

正式审核使用 100 分评分卡：普通用户名称理解 25、定位准确 20、记忆传播 15、实际 SEO 意图匹配 15、品牌差异化与法律风险 15、国际化扩展性 10。要求每项提供证据，目标总分 ≥95 且无商标/合规阻断；不达标则优化页面定位或名称，而不伪造评审结果。

最小验证：
1. 真实用户首次看到名称能否描述“发布、领取、托管自动化任务”，与“卖脚本”区分；
2. 对目标地区完成商标、域名及关键竞品相似性排查；
3. 使用真实站点内容、Search Console 与搜索需求数据评估页面表现；没有数据时标记 NOT_TESTED；
4. 评估命名是否误导用户认为“任务一领取就无需授权、必有收益”。

后续任何外部品牌更名仅变动产品显示/SEO 层，技术路径 `projects/task-shop/` 如未发生实际冲突可保持稳定。
