## P1：七项直接业务效果

先在一个已授权、适配成功且可滚动的真实 ChatGPT 长对话完成最短闭环，使用已有内容，不发送测试消息。涉及轮次时至少有三个可可靠识别的已加载用户提问。先证明开关生效，再检查对应按钮的实际落点。

| 开关 | 关键通过标准 |
| --- | --- |
| `regionTop` 回到回复顶部 | 开启时长回复顶部按钮可用，点击到该回复顶部；关闭后该按钮移除，回复底部按钮不受影响。 |
| `regionBottom` 跳到回复底部 | 开启时按钮点击到该回复底部；关闭后该按钮移除，回复顶部按钮不受影响。 |
| `conversationTop` 回到对话顶部 | 单独验证时关闭 `floatingTop`：开启出现对话回顶按钮且点击到顶，关闭后移除；不影响底部和轮次导航。 |
| `conversationBottom` 跳到对话底部 | 开启时出现底部按钮且点击到底；关闭后移除，不影响回顶和轮次导航。 |
| `turnPaging` 按对话轮次翻页 | 开启后上一轮、下一轮按已加载用户提问顺序跳转，长回复不被当成多个轮次；关闭后移除轮次按钮及数字，顶底按钮保持。边界状态不得产生空跳转。 |
| `showTurnCount` 显示轮次数字 | 在轮次翻页开启且角色可靠时，开启显示实际 `i/n` 并随滚动、翻页更新；关闭后无数字及占位，翻页仍可用。关闭轮次翻页或无法可靠识别时不显示虚构数字。 |
| `floatingTop` 滚动后悬浮回顶 | 单独验证时关闭 `conversationTop`：阈值前不显示，超过阈值后出现，点击回顶后隐藏；关闭后不再出现。两个回顶选项同时开启只保留一个共用按钮。 |

设置经现有轮询应用，不将保存回执当成网页已生效。每次等待可观察的按钮/数字变化并记录耗时；首次以 5 秒作为测试等待上限，超时先区分保存、轮询和适配问题，不直接重复点击或升级为全量回归。

回复顶部/底部当前适用于 ChatGPT、DeepSeek 的已识别长回复；Gemini 和自定义网站不据此要求补同类回复工具栏。当前阶段不做全站点矩阵。
