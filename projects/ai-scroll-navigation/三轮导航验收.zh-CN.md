# Ago 对话滚动导航：三轮回归目标

修复「AI 对话滚动导航」在 ChatGPT 对话置顶后把三轮误报成一轮、随后上一轮和下一轮定位失准的问题。以用户提问为轮次；页面暂时移除屏外 DOM 或替换临时消息键时，已识别的提问仍保留在本会话内。站点确实补载了新提问时允许总数增长；切换到另一会话应重新计数。

| 关键 UI 条件 | 预期 |
| --- | --- |
| 三轮都已识别，从对话底部进入 | 显示 `3/3`；滚动区到当前底部，看到第三轮回复。 |
| 实点置顶，再点一次 | 显示 `1/3`，第一轮提问可见；重复点击不改变位置或总数。 |
| 连点下一轮，末轮再点 | 依次显示 `2/3 → 3/3`；实际落到第二、第三轮提问；末轮额外点击不移动。 |
| 从第三轮提问连点上一轮，首轮再点 | 依次显示 `2/3 → 1/3`；实际落到第二、第一轮提问；首轮额外点击不移动。 |
| 实点底部，再点一次 | 显示 `3/3`；即使跳转后滚动范围变化，也到达新底部；重复点击不移动。 |

上一轮从长回复中间起步时，先回当前轮的提问。测试需从第三轮提问的落点开始往回翻，才能区分这个行为与翻错轮次。

2026-11-24 验证：158 项定向 Node 测试通过。[可重复的 Ago 浏览器用例](tests/virtualized-paging-ego.js) 在[三轮测试页](tests/fixtures/virtualized-paging.html)以真实点击通过上述全序列。置顶后只挂载一轮，第二轮重新挂载时更换临时键，滚动高度从 3600 变到 3400 再恢复；翻页后目标提问在滚动区顶部下方 12 px。该用例使用真实项目导航及自定义配置解析代码，站点补载由测试页模拟。

候选 `0.4.44`（内部 r46）已核对原扩展 ID、网站权限范围、编译源码和包指纹。真实 ChatGPT 测试标签已确认六个已加载提问均有原生消息 ID；该标签不是经核实的用户原页面，且候选未在其中安装。本次源码与浏览器测试通过，Ago 原页面升级及新版本执行仍待验证。

原页面复验前再次核对：0.4.44 包与当前源码一致，网站规则与已有 0.4.43 候选一致。0.4.43 有另一测试文档的安装和执行记录，不能证明用户当前标签的版本。当前浏览器窗口读取超时，且没有用户原标签的任务绑定；确认原会话后，从原「管理 → 更新 / 导入新版」核对版本和网站范围，再用新文档的执行回执及上表逐项验收。

用户反馈原 GPT 页仍有问题后，在独立 Ago 真站测试标签重查：精确文档回执绑定至已启用并注册的 0.4.43/r45，现有网站授权有效。实点底部和置顶得到 `3/3`、`1/3`；重复置顶后补载期间计数一度不可见，之后页面呈现六个真实提问。这条会话不能作为严格三轮验收。任务空间 175 已打开 0.4.44 的原更新审阅，界面显示「当前 v0.4.43 → 新 v0.4.44」「网站权限范围未变化」，预览源码摘要与候选包一致。待确认更新后复验；用户原标签和该页运行版本仍未核实。
