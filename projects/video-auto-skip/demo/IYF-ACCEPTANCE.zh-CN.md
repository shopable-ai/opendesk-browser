# iYF 真实浏览器续验 · 完成条件

续接原目标 **OD-VIDEO-AUTO-SKIP-IYF-LIVE-R1** 的验收合同。在 [iYF 指定播放页](https://www.iyf.tv/play/O3MkOSlztbO?id=fanqXazJzVZ)完成 T01–T04，确认第一版能否支持该站。[本机专项与历史证据](README.zh-CN.md)与实站独立计分；目前实站四项均为 **BLOCKED**。只在 `main` 的 `projects/video-auto-skip/demo/` 写入。

## 开始前

- 优先使用 ego 的原 TaskSpace 17 / p1。2026-11-22 只读确认控制仍交给用户。用户完成真人验证并交回后，先确认原 URL 已进入播放页；不绕过挑战、不换配置重试。挑战页无法证明站点播放器有任何限制。
- 先只读确认当前文档、当前剧集和唯一正片媒体。文档、集、线路、主元素或媒体来源变化时丢弃旧绑定，重新确认后才能操作。只使用已授权的网页和 OpenDesk 公共入口；如需要验证原生 Side Panel / USER_SCRIPT，以实际候选回执为证，普通 ego 页面读数不能替代。原生入口不可用时，分开记录媒体行为和扩展链路状态。
- 初始保持关闭助手的自动下一集；片尾验证先用提前结束的测试区间，避免触发网站原生连播。任何定位或导航结果未知，先只读核对同一目标，不重发。

## 从原文档复跑

1. 用户完成真人验证并确认交回后接回 TaskSpace 17，核对 `p1` 是上方播放页。先观察页面标题、剧集、线路、播放器和选集区域。没有证据证明是正片时，继续只读；不要把第一个元素、最长视频或可见视频当作主媒体。
2. 在同一窗口检查实际原生 Side Panel、已加载扩展 ID、`dist/development`、调试页的服务连接和当前修订。仓库已有 [ego 与实侧栏共用的先例](../../reading-toc/DYNAMIC-PILOT.zh-CN.md)，但它不能证明当前 TaskSpace 已配对。若当前窗口不具备原生入口，保留 ego 的独立网页观察；另一现有 Chrome 路径只有在能合法访问同一播放目标、网站权限和配对已核清时才能补测。若该路径也出现真人验证，交由用户处理。禁止复制会话或切换配置绕过。
3. 在「开发 → Page JS」读取 [只读探测脚本](inspect-iyf.js)，核对编辑器源码与当前目标页后只点一次「运行」。它只报告媒体候选、可读框架、播放状态、时间和可定位区间。`visible` 只表示有渲染区域，不能排除出屏或遮挡；匿名标签只属于这一份快照，不能用作后续写入的选择器。`truncated`、不可读子框架、Shadow DOM 未覆盖或零媒体不等于没有其他候选。后续动作的定位和身份规则须来自实际页面的独立依据。
4. 每次原生 Run 核对 [公开的 Page 回执](../../../docs/api/page-userscript.zh-CN.md)：`USER_SCRIPT`、`preview-evaluated`、源码 SHA 与当前标签/文档绑定，以及该轮业务观察。若技术区未显示 `previewId`，仅在已有授权且匹配当前环境的 `opendesk.dev.result` 路径查询原 Run，或记该字段未暴露；不要重跑旧动作来补 ID。新集、同 URL 重载、切线、文档或元素替换后，禁止沿用旧回执。
5. 按表先确定身份，再验证一次片头、一次子区间片尾和一次下一集。播放结束事件用自然结束或已确认排除原生连播的场景单独观察，避免用跳至总时长来制造 `ended`。定位前确认无未结算动作，且起点与终点在同一可定位区间；监视可见的用户/站点竞争动作及重新绑定。`seeking`/`seeked` 不携带动作来源；落点或归属有歧义，按未知处置。T04 点击前若站点正在原生切集、出现连播倒计时或无法判断原生切集是否已启动，就保持只读。受控导航后分别核对到集、起播和递增时间；回执未知时只看当前身份和媒体，不再点击。

| 实验 | 必须满足的通过条件 | 必留证据 |
| --- | --- | --- |
| T01 主播放器 | 从实际播放页确认作品、季、集、线路 / 版本以及唯一正片；区分广告、多视频、iframe 或动态替换。读到真实 currentTime、有限 duration 与可定位区间，验证 play、pause、timeupdate、ended。无法建立唯一身份或合法访问时停止写操作。 | 页面身份、播放器和所在框架的脱敏标识、有限时长和时间读数、事件与时间线；没有暴露的站点字段注明依据与限制，不猜值。 |
| T02 片头 | 用 [00:00, 01:30]，从约 00:30 正常播放触发一次；落点接近 01:30（误差不超过 1 秒，记录实际值）。暂停设置不恢复播放，超过 01:30 不倒退。用站点控件回拖至片头，观察当前区间内推进，自动动作计数不增加。 | 暂停状态、节目身份、触发时间、请求点、seeked 后读数、回拖后的两次递增读数和动作计数。达到目标前发生内容替换、用户输入冲突或读数无法归属时，该次不能算通过。 |
| T03 片尾 | 对真实时长 D 计算最后 90 秒起点 D−90。在最后 90 秒内选一个结束点早于 D 的子区间；正常进入后只 seek 一次，确认仍播放剩余内容且未导航。观察到新时长时重新计算，不借用旧时长；未知时长验证不得产生由助手触发的片尾 seek。只有在确知不会误触发原生连播时才验证终点恰为 D 的分支。 | 实际 D、区间、进入前后与落点、剩余时间推进、同集身份；换源/新集前后时长和计算结果；未知时长时的动作计数。无法在站点观察的分支单列 NOT_TESTED，本地证据只作补充。 |
| T04 下一集 | 按可靠集序和页面身份唯一确认同季下一正片，线路/清晰度重复不算新集。检查站点实际存在的倒序、可见性、分页/分组/动态加载；不能按列表相邻位置或集号加一直接点击。确认后只做一次受控导航；分别确认进入正确集、且目标主媒体处于播放并持续推进。 | 当前集、候选及唯一性依据、线路去重、点击前后页面身份；进集与起播的独立回执。未唯一确认不点击，已进集但未起播不能算通过。 |

**完成门槛：** T01–T04 的目标站核心条件全部 PASS，实测分支有脱敏证据，无未核清的 seek 或导航回执。站点确实未提供的变体注明观察依据；未观察到的分支保留 NOT_TESTED。出现真实不符标 FAIL；缺少可执行前提标 BLOCKED，并明确恢复需要什么。BLOCKED、夹具通过和静态推断均不能用来关闭这个续验目标。日志不保留 Cookie、令牌、个人信息或媒体资源 URL。

每轮存入 [evidence.json](evidence.json) 的脱敏证据：记录实际 HEAD、候选脚本 SHA、扩展身份与已核对产物指纹、运行环境及连接状态；精确标签/文档和 `previewId` 仅在本机核对，报告用一致的匿名关联号或摘要。时间线记录场景、节目/线路匿名身份、预期和实际定位时间、相关事件、是否发生导航与结果状态。只输出列出的字段，不复制整页 DOM、控制台、请求头、浏览器存储、资源地址或原始异常。

最终冻结同一份候选及实站证据后，由独立审阅者按播放器工程、扩展架构、交互安全、反方审计各评 0–100 分，注明仅审阅或实际独立复跑；无独立能力时标明同一模型分视角自审。修复实质扣分项后重验受影响行为并复评，算术平均至少 **95/100** 且上述实站门槛全部满足才结束。正式同包安装、关闭侧栏继续运行及撤权验证留给后续正式开发。
