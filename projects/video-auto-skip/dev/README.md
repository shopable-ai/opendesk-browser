# 连播助手 · 本地真实视频测试页 R1

这个页面是**真实媒体播放器夹具**，不是第二套侧栏或规则模拟器。它复用 `tests/fixtures/server.mjs` 的 FFmpeg WebM 生成、Range 响应和已经授权的本机路由；不会写入扩展存储，也不会自动执行片头、片尾跳过或自动下一集。

## 启动

需要 Node.js 22+、`ffmpeg`（含 `libvpx-vp9`）和装有 OpenDesk Browser 的 Chrome。**在仓库根目录运行一条命令：**

```sh
node projects/video-auto-skip/dev/server.mjs
```

打开 **http://127.0.0.1:8765/video-auto-skip-fixture/ep-1**。仅监听 `127.0.0.1`；端口 8765 被占用时会报错，不会接管其他服务。初次运行会在系统临时目录生成三段 160×90、6 FPS 的静音真实 WebM 视频（60 / 60 / 75 秒）；Ctrl+C 正常停止后删除本次素材。时长以网页 `loadedmetadata` 和侧栏实际显示为准。

## 最短联调

1. 沿用当前 OpenDesk 的开发扩展（`dist/development` 及其现有 watcher）或从项目正式包 `video-auto-skip.opendesk-tool.json` 走「扩展」审阅安装；授权本地网页功能与用户脚本。不要将 `preview/index.html` 当作扩展。首次启用网页功能后刷新播放页一次。
2. 打开实际「连播助手」侧栏，核对「连播助手本地测试剧」第 1 集的真实时长。保存片头 **0–3 秒**，片尾 **最后 5 秒**（终点留空/End）；在适用的本作品/本集范围保存。关闭并重开侧栏，验证真实读回。
3. 新开或刷新第 1 集的播放页，从视频 0 秒正常播放，查看本页 `seeking/seeked` 与侧栏的已确认跳过。按「定位到结尾前 8 秒」，播放跨过 **55 秒**附近，核对片尾。第 3 集的相同相对规则应从 **70 秒**附近触发，不能使用上一集的 55 秒。
4. 第 1→2 集的实际时长相同，测试同一已确认作用域中的保存、读回和覆盖；不同本集例外与本作品默认不能混淆。第 2→3 集验证不同长度、换源和重新绑定。「同节点换源」只换媒体源，不伪装成切集；不要由它推断新剧集身份。
5. 验自动下一集时，请**单独关闭片尾跳过**、启用侧栏的「自动下一集」，在第 1 集正常播放至自然结束。页面的「下一集导航请求 / 已到达」计数只证明页面观察到的路由动作（含手动），不能证明扩展触发；成功必须再核对真实侧栏的到达和起播回执。需要自动起播可勾选「下一集到达后由测试网站尝试播放」，这仅是测试站模拟正常站点播出行为，失败会记日志。第 3 集为终点，不应重试切集。
6. 停用连播助手或撤销该测试站点的权限后，仍可手动播放、定位和选集，但不应由扩展产生跳过或自动下一集。重新授权后如需联调，按官方安装/授权链操作，勿重置其他站点数据。

## 观察和边界

- 页面记录实际 HTMLMediaElement 事件、实际 `duration/currentTime` 和下一集路由请求/到达次数；不接入扩展内部规则或声称谁触发了 seek。记录被保存在此标签页的 `sessionStorage` 中，最多 12 条；「清空本次日志」只清空本页事件记录，不删除扩展任何保存规则。扩展自己的授权、规则命中、到达及起播回执必须在正式侧栏读取。
- 手动 Seek、返回片头、查看和撤销可能享有扩展既有的回看豁免；重测首次自动跳过应刷新当前播放文档，然后让时间自然跨越起点。按钮「从头播放」不会绕过豁免。
- 这个版本只提供同一明确测试作品、三集正序、一个真实视频元素和同节点换源。两个无关作品碰巧时长相同的隔离、播放器 DOM 节点替换、未知时长、倒序分页及真实网站行为由既有单测/原生专项或后续最小复现覆盖，**不能**凭本页宣称已实播通过。
- 60/60/75 秒视频与现有本地原生验收使用的 210/240/188 秒夹具独立；`startFixture` 默认行为不变。若 FFmpeg 不可用或 Chrome 权限不足，分别记录「服务未启动 / 扩展未联调」，不要拿页面或离线预览代替真实通过。
