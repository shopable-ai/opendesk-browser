## 1. 原始目标：要让用户完成什么

在电视剧、动画等连续视频中，用户希望自动跳过不想重复看的片头片尾，同时保留片头前的剧情及片尾后的彩蛋；按准确顺序自动继续下一集，而不受选集列表倒序、分页、分组、动态加载影响。同一作品尽可能只设置一次，特殊集单独调整；未来本人跨站确认版本后可复用，并允许用户自愿贡献准确时间给其他人使用、反馈错误。

典型过程：打开已支持的剧集网页 → 助手识别作品、季、集、视频版本、时长与主播放器 → 无已保存规则时显示未设置 → 用户用侧栏设置起止、主动查看端点校准、明确选择保存范围 → 后续正常观看时分别执行片头、片尾跳过和下一集识别/切换。作品与集信息优先自动识别，仅无法确认时要求简单纠正。第一版可手动输入时间，无需观看期间调用 AI 视频分析。

核心边界：

- 跳过片头、跳过片尾、自动下一集是**独立开关和独立动作**。跳过片尾不能自动等同于切集。
- 「最后 N 秒」会跳过此区间全部内容，不自动认为片尾之后没有彩蛋。
- 未确认下一集身份，不能按 DOM 列表位置或集号加一盲目切换；结果 UNKNOWN 不重复执行导航。
- 首次未设置不自动生成或启用 90 秒标记。90 秒仅是演示示例。
- 正确顺序、分页/分组/懒加载寻找及防重切，是**首个已支持网站 P1 的核心验收项**，不能全部推迟。
- 不另建浏览器扩展框架。正式开发应按 OpenDesk 的 Extension Type & Ownership Gate 选执行世界与公开 SDK。

## 2. 全量功能需求树（F1–F9）

### F1 当前内容、身份和主播放器识别

- F1.1 自动识别网站、作品、季、集、时长、适用内容版本；缺失/歧义时提供轻量纠正。
- F1.2 确认当前标签页内的主播放器，避免误操作广告视频、预览、背景播放器和多个媒体。
- F1.3 手动换集、SPA 路由变化、换线路、切换版本后重新判断身份与时长。
- F1.4 同名、相同集号和相似片长仅是匹配线索，不能独立证明作品/版本兼容。
- F1.5 按标签页、文档、播放器及集身份隔离草稿与待执行动作；不能串用另一视频的时间/位置。
- F1.6 时长未知时保留已有配置和草稿，不借用上一集时长；恢复时重新校验。
- F1.7 目标播放器消失、版本不匹配、权限不足或身份未知时，停止可能误跳的动作并给出原因。

### F2 片头设置与跳过

- F2.1 常见模式起点固定 00:00，仅编辑结束时间；示例 00:00—01:30，但首次不得默认生效。
- F2.2 固定的 00:00 只做标记，不伪装成第二个拖动手柄。
- F2.3 支持「改为指定区间」，例如 02:00—03:30，保留之前剧情。
- F2.4 指定区间时有两个真正可编辑的端点，具名、分别选中、分别输入；起止不得交叉或静默交换含义。
- F2.5 第一版每类只需一个区间，支持仅当前集修改或显式关闭。
- F2.6 「用当前时间标记片头结束/开始」把播放位置写入当前草稿，不改变视频位置。
- F2.7 「查看片头结束/开始位置」主动定位，不自动保存，也不意外解除暂停。
- F2.8 主动查看、回拖、撤销后的当前区间本次观看暂时豁免，不能马上再次自动跳走。
- F2.9 独立片头开关的显式关闭是个人规则，不等于删除时间，按保存范围继承。

### F3 片尾设置、相对时长和彩蛋

- F3.1 常见模式为「最后 N 秒」，终点固定实际视频结尾，只需调整 N 或开始位置。
- F3.2 **存储相对时长 N，不跨集复制本集计算出的绝对起点。** 45:00 视频最后90秒显示43:30—45:00；48:00 视频重新计算46:30—48:00。
- F3.3 不对片头/片尾区间按整集长变化进行比例缩放。
- F3.4 说明「最后 N 秒」可能包含尾部剧情/彩蛋；只知道片尾开始点不足以断言应切集。
- F3.5 支持「指定区间」如42:00—43:30，跳后继续播放片尾后的内容。
- F3.6 默认只提供「查看片尾开始位置」，不默认直接定位到结束时间、不偷偷减去数秒。
- F3.7 「用当前时间标记」在常见片尾模式换算为距结尾的 N 秒；时长未知时不伪造。
- F3.8 时间未知、起止非法、越界或可能误跳整集时保留配置，禁用危险跳过/定位/保存，给出就近提示。
- F3.9 片尾跳过与自动下一集分别控制、分别触发；不在片尾起点处隐式切集。
- F3.10 支持单集独立片尾规则与显式关闭，保留其他未改项目继承。

### F4 正常集序与准确连续播放

- F4.1 **先确认下一集内容身份，再决定如何导航。**
- F4.2 网站选集列表正序/倒序只影响展示，不改变正常剧集顺序。
- F4.3 下一集位于另一页、另一分组或尚未加载时按需寻找，不能只看当前可见列表。
- F4.4 不能把当前页或当前组的最后一个选项当作作品末集。
- F4.5 同集多线路、清晰度及重复入口不算下一集。
- F4.6 区分正片、预告、花絮、特别篇与合集；缺号、上下篇、合集映射不清晰时不能无条件集号加一。
- F4.7 缺失或不可播放集不能静默跳过；相应状态要可解释。
- F4.8 默认季末停止，不跨季；未来再明确提供跨季选项。
- F4.9 仅在本集实际播放完，或明确允许的剩余区间处理后准备下一集；暂停、缓冲、倍速变化不触发提前切换。
- F4.10 与网站原生自动下一集协调，避免重复切集和相互争抢。
- F4.11 分别核实「已进入目标集」和「目标集开始实际播放」，不把点击成功视为播放成功。
- F4.12 导航结果 UNKNOWN 先核查状态，不自动重放可能已经发生的切集。
- F4.13 暂停、手动换集、取消、切换来源/版本或身份变更后，旧 pending 动作全部失效；新集按自己身份/时长和规则重建。
- F4.14 关闭侧栏或保存规则不能补执行旧动作。

### F5 停止原因与状态准确性

- F5.1 已看到当前最新更新：有可靠的更新/目录依据。
- F5.2 本季已完而未跨季：有季与末集依据。
- F5.3 已确认作品完结并看完末集：有独立完结依据。
- F5.4 下一集没找到或列表未加载完整：必须显示「未找到/待加载」，不能显示「已看完」。
- F5.5 下一集存在但暂不可播放：单独报告。
- F5.6 进入下一集但尚未实际播放：单独等待/核实。
- F5.7 切换结果不确定：单独标 UNKNOWN，不重复导航。
- F5.8 时长未知、主播放器不可用、权限不足、版本冲突等阻断在唯一简明状态区说明。

### F6 保存范围、继承和规则优先级

- F6.1 具体时间按照作品、当前季和适用视频版本保存；网站级设置主要是功能偏好。
- F6.2 第一版支持**作品默认**和**当前集独立设置**；以后可增加指定集数范围。
- F6.3 单集例外只覆盖用户实际改动的项目，其余片头/片尾/下一集继续继承。
- F6.4 明确关闭某一项也是规则值，不被公共规则或作品默认覆盖。
- F6.5 优先级按项目为：个人单集 > 个人集数范围 > 个人作品默认 > 匹配的公共规则。
- F6.6 同名、相同集号、近似时长不足以直接跨站共享，作品/季/集/版本必须匹配或经确认。
- F6.7 首次创建规则默认存本作品当前季；「调整本集」进入默认仅本集。
- F6.8 保存按钮应直接写「保存本作品设置」或「仅保存本集」，不能模糊表示范围。
- F6.9 支持恢复作品默认；恢复不是删除原作品规则。
- F6.10 草稿绑定作品、季、集、版本与保存范围，切换范围或内容时不能静默迁移或丢失。
- F6.11 侧栏关闭后正常生效的已保存规则继续运行，不因界面开合补跳。
- F6.12 本地数据、公共贡献各走独立保存/提交动作，不能暗中上传。

### F7 窄侧栏时间设置与最少控件

- F7.1 保留：作品/季/集及必要纠正、片头开关与时间摘要、片尾开关与时间摘要、自动下一集开关、保存范围、具名保存、一处状态区。
- F7.2 推荐**常用端点固定 + 特殊双端点 + 数字精调 + 主动查看**的混合模式，而非全双端点或纯数字。
- F7.3 常见片头固定起点 00:00，常见片尾固定终点视频结束；固定端不能被拖动。
- F7.4 特殊区间才开放起点与终点两个手柄；每个时间项目同时只有一种模式。
- F7.5 一次只展开当前编辑的片头或片尾，另一项保持简洁摘要；不在一条窄整集轨道塞四个端点。
- F7.6 约360px侧栏为主要设计假设，兼顾320px/400px；实际宽度后续核验。
- F7.7 整集几十分钟压入窄轨道时拖动不精确，采用清楚标注的局部窗口，例如开头/结尾约5分钟，**窗口范围不是时间规则上限**。
- F7.8 移动或扩展视野不改变保存时间；拖动中刻度稳定，数字输入可在提交后让窗口覆盖对应时间。
- F7.9 起点/终点数字始终可选，具名、秒级输入、键盘箭头微调、稳定Tab顺序和可见焦点。
- F7.10 两手柄接近仍可使用字段选择，不能仅靠颜色区分端点或错误。
- F7.11 未设置时不画出假生效规则；区分草稿、已保存、不可用、正在查看、错误状态。
- F7.12 不增加 AI 对话框、多步向导、工作流编号、视频波形、多轨剪辑或大型诊断面板。
- F7.13 三个功能开关独立；若开启作为默认偏好，没有实际时间标记时不得执行该项跳过。
- F7.14 只用按情境显示的取消/返回/撤销入口，不常驻堆砌三组按钮。

### F8 拖动、取值、保存、定位、撤销的正确语义

- F8.1 拖动手柄、松手、修改数字只改变**未保存草稿**，不直接移动视频播放位置。
- F8.2 数字和滑块双向同步；视频自然播放不能反写片头/片尾标记。
- F8.3 保存只提交规则，**不补执行已错过的跳过或待切集，不解除暂停**。
- F8.4 后续自然播放经过尚未触发的规则可执行；编辑期间积压动作和旧触发点永不补执行。
- F8.5 「用当前时间标记」将播放器当前位置填入选中端点的草稿，默认片尾换算成剩余秒数；**不移动视频**。
- F8.6 「查看片头结束位置」或「查看片尾开始位置」才主动改变播放器播放位置；**不自动保存**。
- F8.7 主动查看、撤销跳过或用户回拖时临时放行关联区间，并取消旧待切集；保存和关闭侧栏不能立刻撤掉这次豁免。
- F8.8 手动查看片尾期间即使到达结尾，本工具也不能立即自动切集。
- F8.9 「返回原位置」回到首次开始校准前的位置，仅同集同版本有效；尊重用户校准过程中最新的暂停/播放选择。
- F8.10 「撤销自动跳过」回跳过前的位置并防止本次观看立刻再次跳过；不同于返回原位置。
- F8.11 「取消修改」只丢弃草稿，保留已保存规则，也不等于返回视频位置。
- F8.12 主动回拖只放行与回拖相关的区间，不无故禁用其他尚未到达的规则。
- F8.13 恢复正常观看后基于当前身份和播放位置评估下一次事件，不重放过期动作。
- F8.14 换集、换源/版本或主播放器变化时，旧草稿、查看返回点、撤销位置及 pending 跳过/切集不得落到新内容。
- F8.15 默认使用「主动查看」，不随拖动实时定位，也不松手必定位，避免打断观看。
- F8.16 暂停本助手自己的连播不等于网站原生连播已被可靠暂停；必须后续实站验证。

### F9 跨网站复用与多人共享（后续阶段）

- F9.1 本人在同站对同作品/季/兼容版本复用。
- F9.2 本人跨站复用先确认作品、季、集、版本对应关系，不能仅凭名称或片长。
- F9.3 用户明确自愿贡献标记，本地保存与公开贡献分开。
- F9.4 其他用户匹配适配版本后可使用，并显示规则来源。
- F9.5 个人单集与作品规则优先，公共更新不覆盖用户显式选择。
- F9.6 公共更新不得在本集播放途中突然替换已经采用的规则。
- F9.7 支持错误反馈、修正、停止使用不匹配规则。
- F9.8 公共服务离线不影响已保存本地功能；先评估合法可用的现成时间库再决定自建。
- F9.9 跨站复用和多人贡献都必须实际闭环，不能只做上传按钮和空接口。

## 3. 规则模型示例与边界

| 用例 | 可见时间 | 保存语义 | 特殊说明 |
| --- | --- | --- | --- |
| 首次无规则 | 未设置 | 无有效时间值 | 90秒演示不生效 |
| 常见片头 | 00:00—01:30 | 起点固定零、结束90秒 | 只拖结束 |
| 中段片头 | 02:00—03:30 | 指定120—210秒 | 前段剧情保留 |
| 45分钟片尾 | 43:30—45:00 | 最后90秒 | 终点固定结尾 |
| 48分钟片尾 | 46:30—48:00 | 仍是最后90秒 | 重新计算起点 |
| 彩蛋前区间 | 42:00—43:30 | 指定2520—2610秒 | 跳完继续后续内容 |
| 当前集关闭片头 | 已关闭 | 本集显式关闭 | 片尾和连播仍继承 |
| 时长未知 | 最后90秒，待确认 | 配置保留 | 不虚构总时长 |

时间区间合法性：起止有序且不越界，不静默交换端点；输入非法时就近提示并阻止危险保存。第一版每类一个区间；数字输入可以超过5分钟显示窗口，窗口不是配置时长的上限。

### “需求—界面操作—预期行为”关键表

| 需求 | 用户操作 | 预期行为 |
| --- | --- | --- |
| 设置常见片头 | 调整唯一结束端点 | 零秒固定，视频不移动 |
| 常见片尾 | 改最后N秒 | 保存相对时长、换集重算 |
| 剧情中的片头 | 改为指定区间、选两端 | 不跳过前段剧情 |
| 保留片尾彩蛋 | 指定片尾起止 | 只跳区间，后续继续播放 |
| 精确校准 | 数字/键盘/拖动 | 更新同一草稿，不自动定位 |
| 用当前时间标记 | 选择端点并点击标记 | 只填写草稿 |
| 查看端点位置 | 点击具名查看 | 视频定位，不保存 |
| 暂停校准 | 暂停后查看/返回 | 不意外恢复播放 |
| 本集例外 | 只修改片头 | 其他项目继承作品默认 |
| 切保存范围 | 本作品 ↔ 本集 | 有草稿先保护，不静默迁移 |
| 保存/取消 | 点击具名保存或取消 | 不补跳；取消仅丢弃草稿 |
| 回拖/撤销 | 用户拖回或撤销 | 本次对应区间不立刻再次跳 |
| 未知时长 | 切换到未知总时长 | 保留值，禁用依赖时长行为 |
| 非法区间 | 起点大于终点等 | 就近提示，不保存非法值 |

## 4. 侧栏预览与播放测试边界

- 预览文件：[preview/index.html](preview/index.html)。用示例作品、集数和片长审阅侧栏；本页可编辑设置，但不连接播放器，也不是可安装的 Sidebar Tool。
- 侧栏保留作品/季/集、片头、片尾、下一集、保存范围与一处状态。离线预览检查首次未设置、常见及自定义区间、彩蛋前的片尾、拖动与数字和键盘一致、草稿与保存/取消、作品默认与单集例外、非法区间和状态反馈。
