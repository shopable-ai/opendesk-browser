特别重要：当前与未来要分开

  • 当前正式源码：只有两个固定 Task 的委托清单；没有通用动态关联接口。
  • 近期可做：一个添加向导、可复制的 Codex 提示词、任务安装与权限说明。
  • 未来框架能力：可信选择任意已安装 Task，再单独审阅授权 Web Flow 调用；不得由沙箱自行提权。

必要的用户反馈

开发中 ≠ 已安装已安装 ≠ 已授权执行完成 ≠ 业务成功UNKNOWN 不重放

正式实现应有空列表、缺权限、版本变化、任务停用、网络断线、手动恢复、升级撤权等状态，并以真实回执驱动 UI。
