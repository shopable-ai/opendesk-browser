Web Flow · V0.3 界面评审原型

OpenDesk 内的应用工作台 · 仅模拟交互，不访问网页、不申请权限

设计原则

Web Flow 不复制“开发”编辑器，也不接管“我的”任务安装器。它负责组织任务、自动运行授权状态、结果和交接。

你可以这样体验

  1. 先在概览打开自动执行总开关。
  2. 在脚本搜索、收藏、查看详情并做模拟授权。
  3. 通过添加脚本体验固定版本安装审阅。
  4. 在记录查看完成、错误和 UNKNOWN 的区别。
  5. 切换 2 / 20 / 100 条和窄侧栏体验列表策略。

Web Flow

让已安装脚本有序地运行

交互原型
仅本页内存模拟 · 不连接 OpenDesk / Chrome / ChatGPT

评审重点

状态准确：运行完成不等于网页业务成功；结果持久化不等于已送回 ChatGPT。

授权分层：总开关、每条脚本授权、安装状态、Chrome 站点权限相互独立。

开发者字段按需展示：普通用户只看任务、网站和结果。taskId、requestId、runId、resultId 等放在“技术详情”。

键盘

  • Tab / Shift+Tab：操作控件
  • 方向键 / Home / End：页签
  • /：脚本页聚焦搜索
  • Esc：关闭对话框 / 退出详情
  • Enter / Space：操作按钮
