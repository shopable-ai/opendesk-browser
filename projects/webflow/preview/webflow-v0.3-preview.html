设计原则

Web Flow 不复制“开发”编辑器，也不接管“我的”任务安装器。它负责组织任务、自动运行授权状态、结果和交接。

你可以这样体验

  1. 在概览查看待处理事项和自动运行状态。
  2. 在脚本搜索、收藏、查看详情并做模拟授权。
  3. 通过脚本 → 添加体验固定版本审阅。
  4. 在记录核对运行、网页效果、保存和原聊天交付。
  5. 切换 2 / 20 / 100 条和窄侧栏体验列表策略。

评审重点

状态准确：运行完成不等于网页业务成功；结果持久化不等于已送回 ChatGPT。

授权分层：总开关、每条脚本授权、安装状态、Chrome 站点权限相互独立。

开发者字段按需展示：普通用户只看任务、网站和结果。taskId、requestId、runId、resultId 等放在“技术详情”。

键盘

  • Tab / Shift+Tab：操作控件
  • 方向键 / Home / End：页签
  • /：脚本页聚焦搜索
  • Esc：关闭对话框 / 退出详情
  • Enter / Space：操作按钮
