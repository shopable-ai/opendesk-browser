# 运行与授权 · 本轮局部 UI 评审量表

范围：同一冻结源码候选的离线完整宿主。评价用户能否理解并核对批准范围、编辑与审核、选择和复制原文、返回原入口。评分不是当前 0.3.8 安装、真实任务、读屏或原生 IME 验收。上一轮双业务列方案已被用户否定，不继承其设计结论或旧分数。

| 维度 | 分值 | 可观察标准 |
| --- | ---: | --- |
| 信息层级与阅读顺序 | 25 | 标签与值对应明确（10）；JSON 为完整结构化内容、标题与内容顺序合理（10）；短信息与长内容的排版稳定、不随字符阈值跳变（5） |
| 操作与状态理解 | 25 | 审核与批准区别明确、没有导航引发执行（10）；生成后当前复制操作突出（5）；低频身份/诊断保留渐进展开（5）；原文与授权草稿保留（5） |
| 视觉与空间 | 20 | 原蓝色风格和控件一致（8）；对齐、间距、主次关系清楚（8）；信息密度与阅读宽度合理（4） |
| 本轮受影响的可访问性 | 20 | 实际键盘顺序、可见焦点和 Escape 返回（8）；字段标签/错误关联、审核就绪提示（6）；长内容换行、无截断或水平溢出（6） |
| 范围与证据 | 10 | 来源/原值/权限边界明确（4）；字段、指令、长审核完整宿主图与同候选操作证据齐全（4）；未测项如实标注（2） |

每项按实际证据评分并写明扣分，不因目标分数补分。自然换行本身不扣分；只扣截断、水平溢出、含义对应不清或焦点被遮挡等实际问题。未测原生功能不转为此离线分数，也不凭旧图或旧候选通过。

通过目标：独立总分 ≥95/100，且无未解决的阻断问题。低于目标时只修具体可证缺陷，再复核受影响项；评分不能替代用户审阅。
