# 视频播放与下载实测（2026-11-27）

本次使用 ego(lite) 中实际安装的「视频下载」侧栏 0.3.3 和日常 `dist/development`，验证单页检测、Chrome 下载回执和磁盘文件。

## PineShorts 第 1 集

[第 1 集](https://zh-hant02.pineshorts.com/watch/DSQQ19PAG)正常播放。浏览器收到两条 HTTP 200 的 HLS 媒体清单；各含 31 个 TS 分段及 `#EXT-X-ENDLIST`。两条均声明 `METHOD=AES-128`，未声明 `KEYFORMAT`。这是 HLS 分段加密；当前证据没有证明使用 DRM，也没有证明两条清单代表不同画质。侧栏将两项标为 `encrypted · 仅检测`，下载按钮禁用，未发起任务。没有读取密钥。

播放清单是分段索引。播放器可以按需获取并解码媒体，但缓冲区不保证包含整集，也不等同于已封装的文件。页面当前的 `blob:` 播放地址和解码后显示的画面都不能证明存在可导出的原始文件。

站点的可见入口有选集、分享、播放控制和「安装 PineShorts」。安装网站应用不等于导出视频：未找到该集的官方文件导出入口，也未证实应用内离线。[官方条款第 4 节](https://pineshorts.com/terms?language=en)限制绕过内容保护和未经授权复制或录制受保护内容。如需文件，可向 `support@pineshorts.com` 询问该集是否提供授权下载。

## 授权 AES-128 HLS 分段下载开发实测

**授权样片的密文下载通过。** 本项目 [Node 开发入口](scripts/export-authorized-aes128.mjs) 用仓库自制 H.264/AAC TS 和临时密钥构造了三段 AES-128 VOD 夹具，通过本机 HTTP 实际传输。仅在测试适配器中将允许的 HTTPS 源映射到本机；源码没有开放本机地址或改变 Chrome 权限。该夹具验证分段传输、密钥匹配和落盘，未校验整条流的播放时间线。没有使用 PineShorts 的分段或密钥。

| 阶段 | 实测结果 |
| --- | --- |
| 获取 | 只请求授权单匹配的清单及其中 3 个分段，按媒体序号 308、309、310 获取。没有请求清单里的密钥地址；缺段 404、源站拒绝 403 停止任务。 |
| 校验 | 校验清单与各段密文的 SHA-256；用内容方独立提供的密钥在内存核对每段明文 SHA-256 和 TS 结构。媒体序号派生 IV、显式 IV 均通过。密文篡改、调序、错密钥、段数不符、DRM 或跨源均拒绝。 |
| 发布 | 逐字节读回 3 个原始密文文件（7,344、7,536、7,712 字节，共 22,592 字节），SHA-256 全部匹配。授权到期、下载途中删除授权单或在已暂存首段后发生传输及完整性失败，均没有发布目录，也没有留下暂存数据。 |

样片和[校验回执](../../artifacts/video-downloader/authorized-aes128/aes128-export-jNdA5e/receipt.json)保存在 Git 忽略的本机目录，只含密文和回执。临时密钥已随夹具清理。16 项授权导出测试和 3 项现有加密及 DRM 拒绝回归通过；没有改动 0.4.0 正式包或固定 Host，也没有验证真实侧栏的加密保存。合并、MP4、FFmpeg 及生产验收延期。**PineShorts 第 1 集尚未下载**；仍需内容方提供官方或明确授权的文件或导出来源。
