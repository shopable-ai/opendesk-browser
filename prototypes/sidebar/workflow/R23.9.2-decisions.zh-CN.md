# Workflow R23.9.2 · 本机 Codex 与网页摘要授权决策

- 原型交付：单文件 `index.html`，不依赖远程资源；界面中不出现“模拟检查”，但顶部验收说明明确标注状态仅是设计示例，不代表真实 Native 连接。
- Codex 默认来源：本机 Codex，正式就绪态为“Codex 已就绪 / 重新检查”；不可用时“尚未连接 OpenDesk / 连接 OpenDesk”。真正连接状态必须由正式扩展 `describeLocalCodex()`、Native permission 和 Codex probe 决定，HTML 不联网、不连接 Native。
- HTTPS 配置仅用于接口、模型、演示密钥的离线格式检查。格式通过不代表服务可用。
- **不要默认勾选网页摘要共享**：用户尚未同意的网页 DOM/摘要不能随模型来源切换自动披露。删除设置页的常驻“允许向此 AI 来源提供页面摘要”勾选框，改为遇到网页观察需要时在对话中显示接收方与范围，一次点击“允许本轮并继续”，无需回设置页和重发原任务。
- HTTPS 每轮独立同意、无跨轮默认勾选或持久授权；拒绝不得写入。授权绑定提供方、精确 Endpoint 和模拟文档。更改接收方、文档、网站权限后原授权不可使用。Codex 正式版的网页语义摘要许可继续以 `src/ui/workflow/workflow-view.js` 实现为准：按本机会话和 origin 保存至多 30 分钟，任务逐次绑定文档；HTTPS 每轮明确批准。
- 原型不连接 AI、RunHost 或真实网页，仅操作模拟 DOM，`workflowPreviewState()` 只能作为产品状态示例；不能把绿色状态或模拟读取记作真实服务验收。
- R23.10：使用现有 React Root + Portal 转移可信 UI 所有权，保留现有 Browser SDK、Provider、会话、审批与权限控制；待用户确认本原型后再开展正式迁移。
