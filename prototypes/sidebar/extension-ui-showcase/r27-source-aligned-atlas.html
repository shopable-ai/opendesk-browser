完整规范

设置页

P01 + P02：一个页首、一个 Settings Group、一处 Switch；保存失败保留值。反模式：每个字段独立 Card、重复启用开关。

搜索列表页

P03 + P04 + P16：搜索优先、可清除，行操作在 More，空态能恢复。反模式：两排工具栏、列表项多层边框。

创建 / 编辑页

P06 + P07 + P13：主字段清楚、独立返回、未保存保护；未知写入先核对。反模式：默认大 Drawer、异常时偷偷重试。

运行环境安全：仅经审查的宿主 React 可直接导入已有 src/ui/react/components/ui 和宿主 CSS；独立 HTML/React/Vue Tool 需依自身打包器编译、使用自己的 scoped CSS 和公开 SDK。此参考绝不提供 Host 私有 API 或额外权限。

可信 React · 搜索列表

放在 src/ui/react/tabs/，由现有 Root 渲染；需要本仓库 React 与现有 Design CSS。

import * as React from 'react';
import {Button} from '../components/ui/button.tsx'; // 放在 src/ui/react/tabs/ 下
export function SearchList({items = [], onCreate}) {
  const [query, setQuery] = React.useState('');
  const inputId = React.useId();
  const visible = items.filter(item =>
    item.toLocaleLowerCase().includes(query.toLocaleLowerCase()));
  return <section className="od-stack">
    <header className="od-page-head">
      <h2 className="od-page-title">条目</h2>
      <div className="od-page-actions">
        <Button variant="primary" onClick={onCreate}>新建</Button>
      </div>
    </header>
    <div className="od-toolbar">
      <label htmlFor={inputId}>搜索条目</label>
      <input id={inputId} className="od-field" value={query}
        onChange={event => setQuery(event.target.value)} />
    </div>
    {visible.length ? <ul>{visible.map(item =>
      <li key={item}>{item}</li>)}</ul> :
      <p role="status">没有匹配项，请清除搜索。</p>}
  </section>;
}
// 由现有 Sidebar React Root 引用该组件；不新建 createRoot / Host。

独立 Vue Tool · 搜索页

SFC 放在已有 Vue Tool 的源码目录，交由其已安装的 Vue 构建器处理；不注入 Host。

<script setup>
import {ref, computed} from 'vue';
const query = ref('');
const rows = ['设置', '导入', '历史'];
const visible = computed(() =>
  rows.filter(row => row.includes(query.value)));
</script>
<template>
  <main class="tool">
    <label for="tool-search">搜索功能</label>
    <input id="tool-search" v-model="query" type="search">
    <ul v-if="visible.length">
      <li v-for="row in visible" :key="row">{{ row }}</li>
    </ul>
    <p v-else role="status">没有结果，请修改搜索词。</p>
  </main>
</template>
<style scoped>
.tool{display:grid;gap:8px;min-width:0;padding:12px}
input{width:100%;min-width:0;min-height:36px;border-radius:8px}
</style>
<!-- 仅供已有 Vue SFC Tool 构建使用；不注入可信 Host。 -->
