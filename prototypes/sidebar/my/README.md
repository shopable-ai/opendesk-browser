# “我的”页离线交互原型

入口：[index.html](index.html)。直接用浏览器打开，无需构建或服务。

**当前阶段：设计与离线交互原型。** 本轮重做定时计划列表、新建/编辑计划，补齐独立任务管理。正式 React、SDK、Host、公共 CSS 和开发原型未由本任务修改；不构建安装、不提交发布。目标与功能处置见[目标规格](../../../docs/framework/my-ui-ux-r1-20261114.zh-CN.md)，行为条件及当前证据见[测试规格](../../../docs/framework/my-ui-ux-r1-test-spec-20261114.zh-CN.md)，设计入口见 [DESIGN.md](../../../DESIGN.md#my-ui-ux-20261114)。

## 可操作路径

- 「我的」→ 时钟图标 → 定时计划 → 新建 → 填写名称/任务/目标/时间 → 检查计划 → 保存计划 → 该计划详情。编辑和取消返回原详情；新建取消返回来源列表或管理页。
- 计划左侧显示状态图标和文字；点主体及箭头进详情，右侧图标仅暂停/恢复未来调度。暂停不会停止正在运行的任务；当前模拟运行期间仍可在底部停止。
- 「我的」右上角、时钟左侧的管理图标，或计划列表“管理执行任务”→ 搜索名称/ID/网站、带数量的启停筛选 → 版本/网站/关联计划、任务开关、新建计划、更多操作中的复制到开发/固定范围/卸载。顶部搜索与添加保留，集合底部不再重复管理入口。
- 表单“管理任务”→ 管理页 → 返回计划编辑器，保留原字段、错误、滚动与焦点；此入口隐藏管理页的新建计划，避免覆盖草稿。编辑绑定原固定任务，不能暗中换绑。切开发也保护尚未保存的原计划。
- 点击脚本行运行图标 → “参数与运行”→ 表单/JSON → **取消 / 运行任务**。继续沿用约60px脚本行和原业务布局，不恢复顶部示例网页卡片。
- 添加任务的“选择/拖放文件、任务目录、新建脚本”各司其职。目录是添加入口，不替代管理页。

## 本轮设计

沿用开发原型的白底、轻分隔和紧凑层级。列表采用左侧状态、中间名称/时间/明确任务、右侧具名图标，不以82px行高作为完成指标。恢复用循环箭头，任务启用用开关，避免把调度、安装启用与当前Run/Stop混为一谈。主体详情箭头、具名辅助入口、可见焦点和提示共同保证可发现性。

表单按名称、执行任务与目标、执行安排、保存后状态组织；任务选择器全宽，“新建脚本 / 管理任务”保持可见。重复规则为原生radio；每天/每周共用并保留时间，单次日期时间独立保留。保存后状态用原生radio正向选择“按规则执行 / 暂停”，直接显示结果说明。检查面板再次列明对象、目标、规则与暂停结果，固定底栏只承担“取消 / 检查计划”。

输入边界使用原canonical `--od-input-border`快照，装饰分隔保留轻色。离线HTML样式不复制到公共产品样式；后续正式实施沿原Tokens、组件、唯一React根和业务owner。

## 演示边界

### 完整结果查看（2026-11-15）

已补齐原型遗漏的“查看完整原值”路径，提案文案为 **展开图标＋查看完整结果**，展开后为 **收起完整结果**。只在内容截断或隐藏敏感字段时显示，轻量文字按钮放在结果下方；保持可发现性，不使用无文字的纯图标。最近结果与运行记录均可独立查看，敏感内容有就近可见提示；收起、切换任务、离开任务页、折叠记录或页面进入后台后恢复隐藏。查看不修改原结果，无须额外保存按钮。

体验入口：右上角 **⋯ → 完整结果（无需展开）／长结果（查看完整结果）／敏感字段（查看与再隐藏）**。使用“提取网页摘要”的离线样本演示通用结果行为，不执行百度搜索；全部字段仅为示例，无真实凭据。正常任务列表仍保留原入口。

本增量的定向检查和候选指纹见[测试规格第9节](../../../docs/framework/my-ui-ux-r1-test-spec-20261114.zh-CN.md#9-完整结果查看增量2026-11-15)。此前79条与独立评分属于旧候选，本次不沿用；真实产品原按钮及正式 React 未由本增量修改。

所有状态仅存在页面内存，刷新恢复示例。不执行脚本、不读取网页、不访问网络/存储/剪贴板，不安装任务、不创建真实计划。右上“演示状态”提供空任务、网页不可用、失败和未知结果；切换会重置任务及参数，计划仍保留。

文件入口只读预览用户明确选择/拖放的单个.js/.json，最多1MB、正文最多6000字符；关闭/离页后的迟到读取受保护。识别format不等于包验证。目录仅展示示例安装态。“复制到开发”仅展示交接位置及覆盖未保存源码的风险，不传递源码、不伪报已复制；“查看开发入口”只是导航。

北京时间、每周规则和“明天/下周”均是演示时间，不是实际调度计算。真实完整规则/时区/错过策略、AI、导入验证、复制草稿、权限及安装能力仍归原产品owner，不因原型简化而删除。
