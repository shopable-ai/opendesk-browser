# 百度参数与运行 · 离线验收

目标：用户只填关键词就能完成一次离线模拟，并在点击前知道脚本会怎样处理当前页。脚本声明动态参数、默认值与适用条件；同一份任务草稿驱动表单、JSON 和运行摘要，提交时冻结有效值用于模拟回执。固定三条结果属于脚本行为，不是普通用户输入。只变更「我的」离线预览。

| 脚本参数 | 默认 | 行为 |
| --- | --- | --- |
| `query` | 无，必填 | 单行搜索关键词，1–120 字符，提交时去掉两端空白。 |
| `target` | `auto` | 「始终新开标签页」开关关闭时自动选择：复用合适的当前百度页，否则从百度首页新开；打开对应 `new-tab`。 |
| `startUrl` | 空（百度首页） | 仅随 `new-tab` 使用；接受单行的百度 HTTPS 同源网址，不接受凭据、站外网址或与自动选页矛盾的非空值。 |
| `showExecutionTab` | `true` | 是否主动切到执行标签页，关闭后仍取结果。 |

按表单切回自动选页会同时清除起始网址；JSON 中省略选填值会恢复脚本默认值。旧 JSON 的 `limit: 3` 可读，任何其他数量拒绝。草稿在当前页面内独立按任务保留，已开始的模拟使用独立快照。

| 检查 | 可观察的通过条件 |
| --- | --- |
| P1 默认路径 | 同表显示关键词、自动选页和切页控件，只需填写关键词。「本次运行」默认收起，保留执行对象和同词读取／换词重搜的提示；无合适当前页时说明从百度首页新开。仅用户触发「模拟运行」产生一个记录。 |
| P2 自定义路径 | 打开新开标签页开关才显示网址行；空值从百度首页开始，合法指定网址出现在展开的摘要和回执中。关闭主动切页后仍返回三条模拟结果；恢复自动清除网址，取消后保留草稿。 |
| P3 表单与 JSON | 双向切换时关键词、目标、网址和前后台选项一致；省略选填键补默认值。无效 JSON 不被覆盖，切表单和提交均受阻。空关键词、非法 URL、冲突选项、未知参数和错误类型有可定位的错误与修正路径；非法目标直接提示合法的 JSON 值。 |
| P4 阻塞与恢复 | 无授权和编辑中撤权都禁止模拟，折叠时原因及模拟恢复入口仍可见，恢复后保留草稿。当前页丢失时自动选页需重新检查，复查入口位于抽屉外。停止后有回执；未知原记录保留提交的关键词与目标，不生成结果或重跑。 |
| P5 键盘与焦点 | 打开聚焦编辑器；Tab 在弹窗内循环，开关、抽屉和底栏可操作，收起不隐藏阻塞恢复操作。关闭或取消恢复入口焦点；当前任务的键盘停止后聚焦最近结果。中文合成时 Enter/Escape 不误运行或关闭。合成事件与实体输入法分开记证据。 |
| P6 视觉与布局 | 按常规侧栏宽度检查。参数同表左标签右控件，仅必填显示星号，标签悬停提示与可访问说明一致。分组样式与现有抽屉一致，状态、错误和可操作的底栏易扫读。 |
| P7 其他脚本 | 「提取网页摘要」保留自己的原生下拉、独立草稿和执行路径；其他任务不能读到百度草稿，回到百度仍能修正原始无效 JSON，运行记录与停止仍可用。 |

门禁：同一 HTML 指纹的 Ego 浏览器证据符合以上条件；独立交互和视觉评审各自严格大于 95/100。交互按默认决策 25、参数一致性 25、阻塞与恢复 25、键盘与回归 25 计；视觉按信息层级 30、常规侧栏的表格配对与动作可达 30、状态可扫读 25、控件风格与焦点 15 计。有阻塞即不通过。以 DOM、可访问性树和操作记录为主要证据，少量截图辅助视觉判断。真实扩展、安装、宿主、百度站点、跨宽度、浏览器缩放和实体输入法不属于本轮验收。
